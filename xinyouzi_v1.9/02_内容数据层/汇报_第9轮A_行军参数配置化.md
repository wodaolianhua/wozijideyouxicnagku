## 二、契约变更（StrategyGame.Contracts/Interfaces.cs）

在 `BalanceConfig` 类、`SiegeDefeatRoutRate` 之后新增两个属性：

```csharp
/// <summary>【第9轮A新增】长途行军每跳月数（绝对月数，非比率）。基准 1：一条相邻边走一个月。
/// 仅长途行军（跳数 ≥ 2）收取，相邻出兵（跳数 = 1）不收。</summary>
public int MarchMonthsPerHop { get; set; }

/// <summary>【第9轮A新增】长途行军每兵每跳粮草消耗（万分比）。基准 200，与
/// <see cref="ArmyMonthlyGrainPerSoldier"/> 对齐。仅长途行军（跳数 ≥ 2）收取，
/// 相邻出兵（跳数 = 1）不收。公式：耗粮 = 兵力 × 本值 / 10000 × 跳数。</summary>
public int MarchGrainPerSoldierPerHopPerMille { get; set; }
```

**B 阶段前置条件**：
- 属性 1：`int BalanceConfig.MarchMonthsPerHop { get; set; }` — 绝对月数，基准 1
- 属性 2：`int BalanceConfig.MarchGrainPerSoldierPerHopPerMille { get; set; }` — 万分比整数，基准 200

## 四、校验器规则（ConfigValidator.cs — ValidateBalance）

```csharp
// 【第9轮A新增】长途行军两参数
// marchMonthsPerHop 必须 ≥ 1：为 0 会让所有行军永远到不了，属配置事故。
if (b.MarchMonthsPerHop < 1)
{
    r.Error(ValidationCode.ZeroValue, $"{loc}#marchMonthsPerHop",
        $"marchMonthsPerHop = {b.MarchMonthsPerHop}，必须 ≥ 1。"
        + "为 0 会让部队永远到不了目的地，属配置事故。基准 1：一条相邻边走一个月。");
}
CheckRatio(r, $"{loc}#marchGrainPerSoldierPerHopPerMille",
    "长途行军每兵每跳粮草消耗", b.MarchGrainPerSoldierPerHopPerMille);
```

规则详情：
| 字段 | 规则 | 合法区间 | 错误码 |
| --- | --- | --- | --- |
| `marchMonthsPerHop` | ≥ 1 | [1, ∞) | ZeroValue（< 1） |
| `marchGrainPerSoldierPerHopPerMille` | CheckRatio 通用万分比 | [0, 100000] | NegativeValue / RatioOutOfRange |
