## 一、任务目标

在「点自己的城」时，除了现有侧栏面板，**新增一个城内视图**：用 Canvas 2D 画出该城的四类建筑
（农田 / 兵营 / 城墙 / 市集），按当前等级显示规模，正在升级的显示进度。
让玩家一眼看出「我这城建到什么程度了」，呼应核心乐趣「像皇帝一样经营」。

来源：交接文档第八节第 1 项【高】——「点自己的城进去，看到建筑一格格长起来。
数据都有（FarmLevel / BarracksLevel / FortifyLevel / MarketLevel / UpgradingBuilding /
UpgradeMonthsRemaining），只差一个场景。」

## 二、数据现状（重点：不用改 Contracts / 后端）

建筑等级数据**已经在 `/api/state` 返回的 City 里**，前端 `Core/Types.ts` 的 `City` 接口已定义：

```ts
farmLevel: number;        // 农田 0-5
barracksLevel: number;    // 兵营 0-5
fortifyLevel: number;     // 城墙 0-5
marketLevel: number;      // 市集 0-5
upgradingBuilding: number;// -1 无；0 农田 1 兵营 2 城墙 3 市集
upgradeMonthsRemaining: number;
```

执行第一步：先 `grep -n "farmLevel\|upgradingBuilding" client/src/Core/Types.ts` 确认字段名一致。
**本任务绝不改动 `StrategyGame.Contracts`、后端、02/03/04/06 任何文件。** 若发现拿不到某字段，
停手写在疑问条里，不要擅自扩契约。

## 三、现有代码入口（先读懂再动手）

- `client/src/main.ts` L54-56：点城 → `hud.openCityPanel(cityId)` 打开侧栏（信息+指令面板）。
- `client/src/State/Interaction.ts` L117-118：同上，`this.hud.openCityPanel(...)`。
- `client/src/Ui/Hud.ts` L461 `openCityPanel` → `renderSidePanel`；L574/615 `renderBuildingRows`
  已经在侧栏里用文字行渲染建筑等级与「在建 X，剩 N 月」。

**建议落点**（执行 AI 可调整，但范围只限 05A 前端）：
1. 在 `renderBuildingRows` 旁边（或城池面板底部）加一个「进入城内」按钮。
2. 点击后切换到一个新的城内场景——可新增 `client/src/Scene/CityInterior.ts`，
   复用现有 `WorldScene.ts` 的 Canvas 2D 绘制模式（不引入 three.js / WebGL）。
3. 城内场景按 `City` 的四类建筑 + 等级，画出简笔方块/图标：等级越高块越大或越多；
   `upgradingBuilding >= 0` 的那类建筑额外画「升 X 级 · 剩 N 月」进度提示。
4. 提供一个「返回」回到疆域图。
