# 人才系统实现说明 v1.0

> 对应项目概览新增要求：「像皇帝一样用人，玩家可以挑选人才，让他们帮忙管理各种事物」。
> 代码：`src/game/talent.ts`（48 项测试）、耦合测试 `tests/talent-economy.test.ts`（25 项）。
> 全部为纯函数，确定性随机，同种子必得同结果。

---

## 一、为什么要有这一层

概览里"可以像皇帝一样用人"这条要求，在原设计里是**缺失的一层**：

- docs/01 §3.4 写的是"将领 = 数值 + 标签"——那是**单个将领**的设计
- 但"挑人、派人、管人事"需要的是**人才池 + 岗位任命**机制

这一层同时解决 docs/01 §7 自审第 4 条：「简版任务系统可能变成每天点一下领奖励，失去决策感」。

**为什么能解决**：不同人才派去做同一件事，效果不同且不可互换。原本"选军事还是选发展"是**题材差异**（现在只能这么取舍），加入人才后变成**人选差异**（这两个人谁更适合干这事）——取舍的颗粒度细化了一层。

## 二、人才的构成

### 2.1 四维数值（1~10）

沿用 docs/01 §3.4 的将领四维，在经营场景下重新映射：

| 维度 | 简写 | 经营层含义 | 战斗层含义 |
|---|---|---|---|
| 统率 | command | 征兵效率 | 部队作战效率 |
| 智力 | intellect | 民心操作 | 情报、外交 |
| 管理 | management | 金/粮/基建 | 补给效率 |
| 武力 | valor | 民心鼓舞（亲卫） | 个人上阵战斗力 |

### 2.2 出身（决定数值区间与特性倾向）

| 出身 | 统率 | 智力 | 管理 | 武力 | 特性倾向 |
|---|---|---|---|---|---|
| **寒门** | 4~7 | 4~7 | 4~7 | 4~7 | 无倾向 |
| **世家** | 5~8 | **6~9** | 3~6 | 2~5 | 纵横 |
| **军伍** | **6~9** | 3~6 | 3~6 | **6~9** | 韬略/ 骑射 |
| **商贾** | 3~6 | 4~7 | **6~9** | 2~4 | 治军 |
| **方外** | 2~5 | **8~10** | 4~7 | 1~3 | 营造 |

**规则**：出身只决定**起点**，不决定上限。方外武力最低但智力满值——他当刺史是天才，当都尉是废物。

### 2.3 性格（影响 AI 决策倾向，纯规则非剧情）

| 性格 | 加成方向 |
|---|---|
| **激进** | 都尉 +12% 战斗、刺史 −10% 民心、工曹 −5% 基建 |
| **持重** | 任务失败率低，各项平稳，工曹 +8% 基建 |
| **狡黠** | 任务成功率高，民心操作差 |
| **刚直** | 民心操作强（刺史 +10%），度支 −5% 金 |
| **贪利** | 度支 +15% 金、−6% 民心；都尉 −6% 战斗 |

**这是纯系统驱动的关键设计**：性格不是用来写剧情的，是用来让同一个人在不同岗位上表现不同的。"贪利"的人放到度支是发财好手，放到都尉就会克扣军饷导致战斗力下降。

### 2.4 特性（加成型标签）

| 特性 | 效果 |
|---|---|
| **治军** | 粮产 +10%（工曹时）；度支时降低粮耗 |
| **韬略** | 战斗效率 +15%（都尉时） |
| **营造** | 基建速度 +15%（工曹时） |
| **纵横** | 民心 +15%（刺史时） |
| **骑射** | 战斗 +8%（都尉时）；骑兵相关 +20% |

## 三、岗位

四个岗位对应四类产出，构成"用人"的抓手：

| 岗位 | 主维度 | 影响的产出 |
|---|---|---|
| **刺史** | 智力 | 民心日变化、征兵效率 |
| **都尉** | 统率 | 战斗效率 |
| **度支** | 管理 | 金收入、粮耗 |
| **工曹** | 管理 | 基建速度、粮产 |

**规则**：
- 一个岗位只能有一个人（任命即顶替）
- 改任会自动清掉旧岗位记录
- 亲卫不可被外派
- 岗位匹配度 `postFit()` 给 0~1 的 UI 提示

### 3.1 加成公式

```
单项加成 = 该维度数值 / 10 × 0.5 + min(经验/500, 0.2)
最终倍率 = 1 + 单项加成 + 特性加成 + 性格修正
```

四个岗位的加成**独立计算**（不是同一个池子），所以派不同的人会改变不同的产出项。

### 3.2 亲卫特权

亲卫（玩家亲自统御的那个人）不占任何岗位，但**恒定提供战斗与士气加成**：

```
亲卫战斗加成 = 统率/10 × 0.5 + 武力/10 × 0.3 + 特性加成
```

实测数值高于同等数值的都尉——**亲自统御就是最强的一支**。

## 四、成长与忠诚

| 状态 | 每日变化 |
|---|---|
| **任职中** | 经验 +2，忠诚 +1 |
| **闲职** | 经验不涨，忠诚 **−1**（怠惰） |
| **亲卫** | 经验 +3，忠诚 +1 |
| **忠诚归零** | 叛走 |

**这是"用人"的时间维度**：你不能把人才全派出去也不能全闲着——闲置会流失。四个岗位最多用四个人，人才池通常有 6~8 人，**必然有人闲置**。

### 4.1 招募

消耗金可招募新人才，人才池无上限。金花光了就没法补充。

## 五、与经营层的耦合

人才加成通过 `EconomyModifiers` 传给经营层：

| 字段 | 消费方| 效果 |
|---|---|---|
| foodRate | 粮产 | 工曹任职 → 粮产 ×1.2~1.45 |
| goldRate | 金收入 | 度支任职 → 金 ×1.2~1.5 |
| moraleRate | 民心变化 | 刺史任职 → 民心变化 ×1.4~1.7 |
| buildRate | 基建/任务速度 | 工曹任职 → 任务推进速度 ×1.15~1.45 |
| foodUpkeep | 粮耗 | 度支任职 → 粮耗 ×0.93~0.97 |
| recruitRate | 可征兵上限 | 刺史任职 → 上限 ×1.1~1.3 |
| combatRate | 战斗 | 都尉/亲卫任职 → 战斗 ×1.45~1.9 |

**实测数据**（`createTalentState(8, 4321)` 四岗位满配）：

```
moraleRate: 1.71  foodRate: 1.14  goldRate: 1.10
buildRate:  1.50  combatRate: 1.90  foodUpkeep: 0.97  recruitRate: 1.10
```

一个人才池满配后，战斗效率提升 90%——**用人的收益是可量化的**。

## 六、测试抓到的 3 个缺陷

### 缺陷 1：人才 id 全局递增，破坏可复现性

`nextTalentId` 是模块级变量，同种子生成两次的人才池 id 不同（1,2,3 vs 46,47,48），导致 `JSON.stringify` 不相等。

**修法**：`generateTalentPool` 内重置计数器。同种子必须产出完全一致的对象。

### 缺陷 2：改任时旧岗位记录未清除

```
王彦博任刺史 → 改任都尉
结果：appointments.governor 仍指向王彦博
```
导致 `totalBonus` 把他的都尉加成算两次，而刺史加成空占一个名额。

**修法**：`appoint` 开头遍历所有岗位记录，移除该人才 id。

### 缺陷 3：`EconomyModifiers` 漏了 `combatRate` 字段

测试读 `mods.combatRate` 得undefined。经营层不直接消费战斗加成，但接口必须完整——否则调用方会踩坑。

**修法**：补上字段并在 `NO_MODS` 中置1。

## 七、测试覆盖（73 项）

| 文件 | 项数 | 覆盖 |
|---|---|---|
| `tests/talent.test.ts` | 48 | 生成/岗位/匹配度/任命/招募/成长/纯函数 |
| `tests/talent-economy.test.ts` | 25 | 岗位影响产出项、人选差异可测量、日推进实测 |

**关键验证**（这些是"用人机制真的成立"的证据）：

- 弱将 vs 强将做同一件事，产出不同
- 同一人派到不同岗位，产出结构不同
- 性格导致的差异可测量（激进在都尉强于持重，在刺史弱于持重）
- 特性导致的差异可测量（营造加基建、治运加粮产，两者不同）
- 工曹任职时任务剩余天数加速下降
- 度支任职时驻军粮耗更低
- 刺史任职时可征兵上限提高
- 四岗位满配时各项产出全面提升
- 亲卫加成不因岗位满配而消失
- 无人任职时产出与无 mods 完全一致（向后兼容）

```
│                                          │
│ 进行中任务                │

│ │ 统8 智5 管5 武8  经验24│        │
│ │ 亲卫（亲自统御）                │        │
│ └────────────────────────────────┘        │
│ ┌────────────────────────────────┐        │
│ │ 王彦博  忠诚 72               │        │
│ │ 寒门·持重·无特长               │        │
│ │ 统7 智6 管3 武6  经验12│        │
│ │ [刺史 71][都尉 96][度支 40][工曹 30] [免] │        │
│ └────────────────────────────────┘        │
└──────────────────────────────────────────┘
```

**交互设计**：
- 每个岗位按钮**显示匹配度百分比**（数字），玩家一眼看出"这人适合干哪个"
- 点击岗位按钮即任命，同岗位自动顶替旧任
- 「免」按钮免职
- 亲卫不显示岗位按钮（不可外派）
- 忠诚 < 30 显示红色（要流失了）
- 推进一日时经营层与人才层同时推进

**颜色约定**：忠于 30 以下红色（危险）；日粮产为负时红色（亏粮）；已任命的人才卡片绿框（在任）。
