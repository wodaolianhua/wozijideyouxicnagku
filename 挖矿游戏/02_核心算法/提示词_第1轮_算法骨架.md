## 游戏规则（算法要实现的行为）

山头是 2D 剖面网格（格子有材质：空气/土/石头/基岩/矿脉；矿脉有矿物种类和硬度）。角色站在地表井口，上下左右移动、朝某方向挖格子。挖到的矿进背包（容量有限），回地面卖掉换钱，攒钱买工具/机器/雇工。

必须实现这些能力（接口已在 `Interfaces.cs` 定义，全部实现）：

1. **移动**（IMovementResolver）：朝方向走一格，目标空气可过、实心挡住、越界拒绝，返回对应结果码。
2. **挖掘**（IDigResolver）：目标格硬度 vs 当前工具 Power，判定能否挖。工具不够→ToolTooWeak、基岩→NotDiggable、空气→Empty、背包满→BackpackFull、越界→OutOfBounds，正常→Ok 并给出挖到的矿/数量/体力消耗。矿脉 OreAmount-1，到 0 变空气。纯函数不改入参。
3. **背包**（IBackpackPolicy）：容量检查装不下拒绝；按单价表算背包估值（供"卖出预估"显示）。
4. **卖矿结算**（ISellResolver）：在地表把背包全部矿按单价表卖掉，算收入 + 明细、背包清空；空背包返回 Income=0。**收入必须填进 `SellResult.Income`，随 `AdvanceResult.Outcomes` 返回——前端靠这个显示"本次卖了多少"，忘了填前端就空。**
5. **购买/雇佣**：买工具、买机器/雇工，钱够扣钱加入列表、钱不够返回 NotEnoughMoney 且不扣钱。
6. **自动产出**（IAutomationResolver）：机器/雇工每 Interval 步挖一次、雇工每步扣 Wage 工资；纯函数、确定性、到点才产出。
7. **快进判定**（IMiningSimulator.FastForward）：推进到"背包满 / 体力耗尽 / maxSteps"三者最先到者为止，状态连续、不需重复下令。
8. **主推进**（IMiningSimulator.Advance）：按 actions 分派上面的操作；玩家无动作时只结算自动产出 + 体力自然消耗。

## 硬性要求

- **纯函数**：相同输入必得相同输出；不读系统时钟、不碰随机全局态（随机传入 seed）、不引用 UI/渲染库。
- **单测覆盖**：每个能力至少覆盖正常路径 + 1 个边界（工具不够、基岩、背包满、钱不够、空背包卖矿、快进到背包满）。目标全绿。
- **随机确定性**：任何随机都走传入的 seed，同 seed 同结果。
- **数据契约（唯一权威，禁手抄）**：所有类型**来自契约工程 `MiningGame.Contracts`**。本包已同步只读副本在 `接口契约_共享类型/`（先读它，含 `Interfaces.cs` 末尾的动作语义说明）。csproj 用 ProjectReference 引用：
  ```xml
  <ProjectReference Include="..\..\MiningGame.Contracts\MiningGame.Contracts.csproj" />
  ```
  （路径按 csproj 实际位置调整。）**禁止在本包重新声明/手抄这些类型**——会变成两套类型，编译必失败。要实现 `Interfaces.cs` 全部接口。契约要改 → 提变更申请给 00，不自己改。
- **状态字段存中间进度**：位置/体力/钱/背包/工人都在 `GameState`，分步推进和快进都要靠它续走，不能要求玩家每一步重新下令。
- **项目结构**：本包内建 .csproj（库）+ 测试 .csproj。仓库根无 .sln，测试时直接指定测试 .csproj。
