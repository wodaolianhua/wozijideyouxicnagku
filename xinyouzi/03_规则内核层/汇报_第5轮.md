## 5. 与裁决单规则的偏差

**无规则性偏差**（补给 floor/余数/Id 升序、池归零、饥荒双条件、事件与占位数不变、per-faction 字典、Clone 深拷贝均逐字落地）。以下为备案性说明：

1. **裁决单原文未读取**：`e:\xinyouzi\00_项目管理\变更申请\…裁决06…md` 在 03 包工作区之外，本轮文件工具被工作区边界拦截。任务书自称自包含，全部规则按任务书第 2/3 节执行，未做独立核对。
2. **GameClock 清零二选一**：选「重建空字典」。理由：`AdvanceMonth` 是第 1 步，Factions 建局后固定、月内不增删，空字典对任意势力读 0，与逐键置 0 等价且更简单。
3. **StateDelta 未扩展**：现有结构（TargetType/TargetId/Field/OldValue/NewValue）足以表达字典项——TargetId 兼作字典 key，无需动契约结构。
4. **写法差异**：任务书示例 `new StateDelta(DeltaTarget.Army, army.Id, …)` 为位置参数构造，实际契约 `StateDelta` 无此构造函数，按包内现成对象初始化器写法落地（字段语义一致）。
5. **契约版本注释**：Models.cs 文件头本无版本号注释，未新增文件头变更块；v1.5 两项变更（per-faction 字段、Clone 深拷贝；第 8 步补给为 Core 行为不涉契约）写入字段 XML 注释。
6. **新测试的饥荒计数断言落在 `state.EventLog`**：流水线第 11 步既有行为 `result.Events.AddRange(state.EventLog)` 会让同一条事件在 `result.Events` 出现两次；本轮未改流水线（不属授权范围），断言改用权威日志。
7. **本地镜像未同步**：本包 `接口契约_共享类型\` 仍是旧内容。按「禁止分发契约」未动，待 00 收工核对后统一分发。
