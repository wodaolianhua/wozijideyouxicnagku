## 0. 背景（已裁决事实，照单执行即可，不必重新论证）

当前版本契约 v1.5：月末第 8 步自动补给会把兵源池按 floor 均分给存活部队并清池；
AI 在第 9 步规划下一月指令。06 模拟器 1000 局数据显示游戏全程死锁：无战斗 →
部队连续 4 月不参战触发和平腐化（每月 −6，`MoraleDecayNoBattlePerMonth`）→
士气归零 → 哗变每月连发、每次散兵 30%（`MutinyRoutRate=3000`，万分比）→
部队被磨到个位数冻结，永远无法越过出兵安全线 500。

00 裁决（裁决单：`00_项目管理/变更申请/20261025-裁决06R4_休整死循环与出兵门禁.md`，
**你不需要读它，背景已全部内联在本文件**）：Rest（休整）指令目前每月每军只能给
士气 +3（`MoraleSystem.CalculateMoraleAfterRest`，冷却 1 月/军防刷），
但和平腐化是 −6/月，且 Rest 不清零连续无战月计数，导致"连续休整"数学上不成立
（净 −3/月）。本轮给休整一个真实机制效果：**部队本月执行过休整，则该月的
月度士气结算既不腐化也不自然恢复**。这样连续休整净 +3/月（+3 由 Rest 结算器给），
可以脱离士气崩溃线；停止休整后腐化照旧。

**契约本轮不改**：`Army.HasRestedThisMonth` 字段早已存在于 v1.5，不新增字段、
不改契约、不改任何数值常量、不动其他任何系统。

## 2. 精确改动规格（只改 MoraleSystem.ResolveMonthlyMorale）

文件：`src/Systems/MoraleSystem.cs`，方法 `ResolveMonthlyMorale(WorldState state)`。

现状要点（行号以你读到的实际文件为准，改动按语义不按死行号）：

- 步骤 0：若 `army.HasRestedThisMonth` 为 true，产出一条 1→0 的翻转 delta；
  随后分支选择只看 `army.HasEngagedThisMonth`（参战分支 / 未参战的恢复·腐化分支）。
- **关键：必须在任何翻转动作之前先捕获旧值**，例如
  `bool restedThisMonth = army.HasRestedThisMonth;`
  捕获后原有翻转 delta（1→0）原样保留产出。

新分支规则（按此优先级）：

1. `army.HasEngagedThisMonth == true` → **原参战分支逻辑一字不动**
   （不恢复不腐化、MonthsWithoutBattle 保持、参战标记消费即清）。
   即使同月休整标记也为 1，参战优先；休整标记的翻转清零照常由步骤 0 完成。
2. 否则若 `restedThisMonth == true` → **新增「休整分支」**：
   - `newMorale = army.Morale`（既不 +MoraleDecayPerMonth 也不 −MoraleDecayNoBattlePerMonth，
     不产出士气变化 delta）；
   - `monthsWithoutBattle = army.MonthsWithoutBattle + 1`
     （休整不是战斗，连续无战月计数照走；越不越阈值都不影响本月，因为腐化挂起），
     计数变化 delta 与既有未参战分支同形产出；
   - 后续哗变判定（moraleFloor ≤ 0 且本周期未哗变）逻辑**原样复用**：
     休整分支不豁免哗变——若部队休整前士气已经是 0，仍按原规则哗变。
3. 否则 → 原未参战恢复/腐化逻辑一字不动。

注释要求（后续维护者要读得懂）：在新分支处写明——
「休整部队本月挂起和平腐化：Rest 结算已给 +3/月（冷却防刷），此处不再自然恢复；
MonthsWithoutBattle 仍累加但腐化暂不生效。停止休整后 −6/月腐化恢复。」

## 3. 必须新增的测试（双向断言，沿用既有测试项目与夹具风格）

在既有测试项目中新增（测试名可用中文既有风格）：

1. **休整挂起腐化（正向）**：一支部队 `MonthsWithoutBattle` 已达腐化阈值
   （≥ MoraleDecayNoBattleThreshold−1，使本月结算后落在腐化区）、`HasRestedThisMonth=true`、
   Morale 为某中间值（如 40）→ 结算后 Morale 保持 40 不变、无士气 delta、
   MonthsWithoutBattle +1、HasRestedThisMonth 翻转 1→0 的 delta 在列。
2. **连续休整不哗变（端到端小循环）**：模拟 12 个周期，每周期先对同一部队执行一次
   RestResolver 成功结算（+3、置标记），再跑 ResolveMonthlyMorale。
   初始士气取低值（如 20）：断言 12 周期后士气 > 0，且全程无 ArmySoldiers 散兵 delta、
   无哗变标记 delta（NewValue==1）。
3. **停止休整后腐化恢复（反向）**：接续上例场景，停止执行 Rest 后连续跑月度结算，
   断言腐化 −MoraleDecayNoBattlePerMonth/月重新生效、士气最终可降至 0 并触发哗变。
4. **休整与参战同月**：HasEngagedThisMonth 与 HasRestedThisMonth 同为 true →
   走参战分支（士气不额外增减、MonthsWithoutBattle 保持参战结算后的值），
   休整标记仍 1→0 翻转。
5. **0 兵部队**：Soldiers≤0 直接跳过的既有行为不变（可不断言，旧测试覆盖即可）。
