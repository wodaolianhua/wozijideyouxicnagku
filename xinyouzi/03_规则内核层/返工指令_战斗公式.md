## 要实现的公式

### 战损率

```
defenseFactor  = 目标城 Defense / 1000.0
commanderRatio = 攻方统帅 / (攻方统帅 + 守方统帅 + 1)     // +1 防除零
lossRate = (BaseLoss / 100.0) × (0.5 + defenseFactor) × (2 - 2 × commanderRatio)
```

### 三种结果

| 条件 | 结果 |
|---|---|
| 守城兵力归零 且 `lossRate < SiegeThresholdLoss/100.0` | **攻陷**：城易主 |
| `lossRate >= SiegeThresholdLoss/100.0` | **击退**：攻方退回出发城 |
| 其他 | **未决**：双方各损 `StalemateLossRate%` |

**三种结果都必须可达，各有单元测试。**

### 兵力损失

```
攻方损失 = 投入兵力 × lossRate
守方损失 = 守城兵力 × lossRate × (DefenderLossFactor / 100.0)
```

### 统帅取值

用契约已有的 `WorldState.GetEffectiveCommand(armyId)`。

**关键**：玩家亲征时该方法返回 `PlayerProfile.Command`，且不叠加任何 Officer 加成。
这个行为已在契约里实现，不要自己另写一套。
