# 命名系统设计

> **本设计的目标**：让游戏有名字可玩，但不阻塞开发。
>
> 执行者在缺少正式命名时用占位名，不自行发挥；玩家可以在游戏里给自己的人物和势力命名。

---

## 一、核心策略：三层命名

| 层级 | 谁命名 | 什么时候 | 说明 |
|---|---|---|---|
| **系统默认名** | 名字生成器 | 自动 | 生成 3 组候选，随存档确定性产出 |
| **玩家命名** | 玩家 | 开局时或游戏中 | 玩家可覆盖任何系统生成的名字 |
| **占位名** | 执行者 | 编码期间 | `Faction_01` / `City_03` / `Officer_02` |

**关键**：占位名只是开发期的临时状态。一旦进入可玩阶段，所有名字都来自生成器或玩家输入。

---

## 二、名字生成器规格

### 2.1 确定性要求（硬约束）

名字生成**必须可播种**，理由与规则层一致：
- 同一 Seed 必须生成同一批名字（否则存档读档后名字变了）
- 批量模拟必须能复现（否则无法对比平衡）

```csharp
public interface INameGenerator
{
    string GenerateFactionName(int factionId);
    string GenerateCityName(int cityId);
    string GenerateOfficerName(int officerId);
    string GenerateGivenName(OfficerSpecialty specialty);
}
```

实现必须注入 `IRandom`，与规则层共用同一个可播种随机源。

**禁止**：`Guid.NewGuid()`、`DateTime.Now`、`Random.Shared`。

### 2.2 词库规模要求

| 类别 | 最低规模 | 理由 |
|---|---|---|
| 势力名用词 | ≥ 60 | 3 个势力不重样，且支持后续扩展 |
| 城池名前缀 | ≥ 40 | 6 座城不重样 |
| 城池名后缀 | ≥ 25 | 组合出足够变化 |
| 人名姓氏 | ≥ 80 | 5-8 个人物不重样 |
| 人名名字 | ≥ 60 | 组合空间足够 |
| 称号 | ≥ 30 | 用于人才专长的可视化 |

**校验**：`NameGeneratorTests` 必须验证 —— 固定 Seed 下 1000 次调用不产生重复名字。

## 三、命名风格约束

### 世界观是完全架空的大陆（决策 D13）

**禁止**：
- 真实历史人物名
- 真实地名
- 有明确现实指向的国名
- 现代词汇

**允许**：
- 古风地名（山川、关隘、地形命名法）
- 中性虚构人名
- 意译型势力名（体现该势力的特征或志向）

### 势力命名法

势力名应体现该势力的**特征**，而不是随机词组：

| 势力定位 | 命名方向 | 例（仅示意风格，非最终） |
|---|---|---|
| 中原霸主 | 正统、秩序、中枢 | 「XX 」「XX 府」 |
| 边疆异族 | 粗犷、地貌、族风 | 「XX 部」「XX 原」 |
| 玩家势力 | 中性、可被玩家覆盖 | 玩家自定义 |

**关键**：势力名是玩家的身份标识，**必须允许玩家改名**。

## 四、玩家命名机制

### 4.1 玩家可命名的对象

| 对象 | 能否命名 | 时机 |
|---|---|---|
| 玩家角色（君主） | ✅ | 开局 |
| 玩家势力 | ✅ | 开局 |
| 招募到的人才 | ✅ | 招揽成功时 |
| 城池 | ❌ | 城池是地理实体，不该玩家乱起名 |
| AI 势力 | ❌ | — |

**设计判断**：城池和 AI 势力不让玩家命名，是为了保持世界的可信度。如果玩家能把任意城叫"我老婆"，世界的沉浸感就没了。

### 4.2 命名规则

| 规则 | 说明 |
|---|---|
| 长度 | 2-8 个字符 |
| 字符 | 中文汉字，不允许空白与特殊符号 |
| 唯一性 | 玩家势力名不得与 AI 势力重名 |
| 禁用词 | 政治敏感词、现实人物名 |
| 时机 | 开局必填；人才可在招揽界面随时改 |

**默认值**：玩家不填就自动使用生成器候选，不阻塞流程。

---

## 五、占位名规范（开发期）

执行者在正式命名定稿前，使用以下规范。**目的是让代码可读，且明确标记"这里待填"。**

| 类型 | 格式 | 示例 |
|---|---|---|
| 势力 | `Faction_{Id}` | `Faction_01` |
| 城池 | `City_{Id}` | `City_03` |
| 人才 | `Officer_{Id}` | `Officer_02` |
| 玩家势力 | `PlayerFaction` | — |

**强制要求**：占位名在代码中必须带 `TODO(命名)` 标记，便于日后全局搜索替换。

```csharp
// TODO(命名): 待接入名字生成器或玩家输入
public string Name { get; set; } = "City_03";
```

---

## 六、验收标准

- [ ] 生成器接入 `IRandom`，同 Seed 产出完全相同
- [ ] 固定 Seed 下 1000 次调用零重复
- [ ] 词库规模达到第2.2 节的最低要求
- [ ] 无真实历史地名、人物名、政治敏感词
- [ ] 玩家可命名势力、君主、招揽人才
- [ ] 玩家命名有长度、字符、唯一性校验
- [ ] 存档读档后名字不变（确定性要求）
- [ ] 占位名全部带 `TODO(命名)` 标记
