# 变更申请目录

## 什么时候用这里

当你需要修改 `StrategyGame.Contracts/` 里的任何定义时。

## 流程

1. 在本目录新建文件：`YYYYMMDD-简述.md`
2. 内容写清楚四件事：
   - 改什么（具体到字段名/方法名）
   - 为什么（不改会有什么问题）
   - 影响哪些包（03 / 04 / 05A / 06）
   - 怎么迁移（旧代码怎么改）
3. 通知所有在岗执行者
4. 修改 `StrategyGame.Contracts/`
5. 各包更新实现，全量 `dotnet build` 通过
6. 运行 `bash E:/xinyouzi/分发契约.sh` 同步副本

## 硬规则

- **不要在自己包里改契约的副本**。副本是自动同步的，下一次分发会被覆盖。
- **不要为了让自己跑通而改契约**。契约设计有问题是契约的问题，走流程解决。
- **禁止修改已冻结的枚举值**。`ActionType` 的 0-5 是永久冻结的。
