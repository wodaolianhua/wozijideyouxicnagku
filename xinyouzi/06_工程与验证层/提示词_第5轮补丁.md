### 2.2 `Program.cs`

1. 新增一个私有静态助手（放在 ParseString/ParseInt 等助手附近）：

```csharp
/// <summary>报告路径默认跟随 CSV：同目录、同主文件名，命名「平衡分析_<CSV主名>.md」。
/// 例：out/result_v16.csv → out/平衡分析_result_v16.md；out/result.csv → out/平衡分析_result.md。</summary>
private static string DeriveReportPath(string csvPath)
{
    string dir = Path.GetDirectoryName(Path.GetFullPath(csvPath)) ?? PackagePaths.GetOutputFolder();
    return Path.Combine(dir, $"平衡分析_{Path.GetFileNameWithoutExtension(csvPath)}.md");
}
```

2. **RunSimulate**：
   - 现 271–273 行硬编码 `"平衡分析_第3轮.md"` 改为 `string reportPath = DeriveReportPath(outPath);`，
     其上方注释更新为「报告名跟随 CSV 主名（CA-1），不同批次 CSV 永不覆盖彼此报告」。
   - ParseOptions 中新增 `--report <路径>` 选项（与 `--out` 同形，用 ParseString 解析，
     存入一个私有静态字段，仿照现有 `OutputPath` 的写法再建一个 `ReportPath`）；
     RunSimulate 中若该字段非空则用它、否则用 DeriveReportPath。
   - 调用 BalanceReportWriter.WriteToFile（现 311 行）末尾补 title 实参：
     `Path.GetFileNameWithoutExtension(outPath)`（即 CSV 主名，如 `result_v16`）。
3. **RunAnalyze**：
   - 现 176–182 行默认报告名改为 `reportPath ??= DeriveReportPath(csvPath);`
     （`--out` 仍作为报告显式路径，语义不变）。
   - 现 198 行 WriteToFile 调用末尾补 title 实参：
     `Path.GetFileNameWithoutExtension(csvPath)`。
4. **PrintUsage**：simulate 用法行补 `[--report <报告路径>]`；参数说明补一条
   `--report 分析报告输出路径，默认与 CSV 同目录，名为 平衡分析_<CSV主名>.md`；
