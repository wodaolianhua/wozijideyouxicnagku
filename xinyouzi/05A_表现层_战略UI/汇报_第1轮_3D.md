## 5. 后端 API 清单（单端口 http://localhost:5178，无 HTTPS/CORS/数据库/登录）

| 端点 | 说明 |
|---|---|
| POST `/api/new-game` | body `{"seed":12345}`（缺省 12345，`<=0` → 400）。`new SimulationHost(seed, 120)`，置 `State.Factions[0].IsPlayer=true`，OrderId 计数复位 100000。返回 `{state, meta}` |
| GET `/api/state` | 返回 `{state, meta}`。`meta = {monthsElapsed, isFinished, winnerFactionId, gameOverReason, upstreamGameOverMonth, upstreamGameOverReason, pendingCount}` |
| POST `/api/order` | body `{action, targetId, secondaryTargetId, amount}`。action 无法解析 → 400；仅入队不结算，后端不做合法性预校验（码 8 原样放行）；`Order.CreatePlayerOrder` → 设 `ExecuteYear/ExecuteMonth`（=下月）/`OrderId`（100000 起自增）→ `State.PendingOrders.Add(order.ToPendingOrder())`。返回 `{queued:true, pendingCount}` |
| POST `/api/tick` | 锁内：IsFinished → 400；快照本月将结算队列 → `host.RunMonth()` → 断言 `turn.Results.Count == 快照条数`（不符 → 500 上报）→ 逐条合并为 `results`（快照字段 + code/message/deltas）→ `events` 取 `State.EventLog` 增量（规避 `turn.Events` 累计量陷阱）→ 返回 `{year, month, results, events, meta, state}` |

- 会话：单局内存会话（一个 SimulationHost 实例 + 一把锁），所有端点串行访问；无存档/读档。
- JSON：System.Text.Json，camelCase + 枚举字符串（与契约 `WireFormat` 线格式规范一致，见疑问条 3）。
- 静态托管：`wwwroot/`（UseDefaultFiles + UseStaticFiles），已装入 client/dist 复制结果。
- 除上述端点外未加任何 API。
