## 2. 桌面化具体交付清单（验收硬标准）

在 R1 已实现的鼠标/键盘能力之上，确保「**电脑浏览器里能纯鼠标 + 键盘从开局玩到结算，全程无需触屏**」：

1. **鼠标为主交互**：上帝视角点击城池选中/高亮/弹信息卡与指令面板；拖拽旋转、滚轮缩放、右键（或中键）平移——保留 OrbitControls 默认或自写等效；所有下令操作（征兵/屯田/修城/休整/任命/军议进军）均可鼠标完成。
2. **键盘快捷键（至少）**：空格 或 Enter = 推进下月；Esc = 关闭当前面板；1/2/3（或等效）= 切换 上帝视角 / 亲征视角 / 人才面板；WASD / 方向键 = 亲征行走（R1 已有，保留）。快捷键在 HUD 角标或帮助里可见，别藏。
3. **桌面布局**：以 ≥1280×720 桌面为基准设计；面板为侧栏 / 浮层，而非移动端全屏遮罩；文字与按钮尺寸适合鼠标点击；不得出现「为手机拉伸」的尴尬布局或极小触控靶区。
4. **触屏兼容（不破坏）**：用触摸检测，仅触摸设备显示虚拟摇杆；桌面端不显示、不拦截鼠标事件。
5. **指针反馈**：可点击对象 hover 时光标变 pointer，提升桌面可发现性。
6. **零回归**：R1 全部既有功能（视角切换、战斗演出、结算面板、人才面板、重新开局、悬停信息卡）全部保留可用。
