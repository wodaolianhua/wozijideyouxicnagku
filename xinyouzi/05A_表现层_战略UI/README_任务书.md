# 05A_表现层_战略UI · 任务书

## 这是什么

玩家在"上帝视角"下看到的部分：战略地图、势力信息、回合结算界面、人才任命面板。

这是**原型阶段唯一的可视化产出**。玩家通过这块 UI 验证"指挥 + 用人"的核心循环好不好玩。

## 铁律

**表现层只读状态、只发指令，永不修改数据。**

具体禁止：
- 禁止在 UI 层直接修改 `WorldState` 的任何字段
- 禁止在 UI 层做数值计算（所有计算在 `Resolver` 里，UI 只显示结果）
- 禁止在 UI 层自己判断指令是否合法（合法性由 `Resolver` 判断，UI 只显示返回的拒绝原因）

违反这三条，游戏逻辑就会散落在 UI 里，后期无法维护。

## 技术要求

**语言待定，取决于引擎选型。** 两种推荐方案：

| 方案 | 技术栈 | 适用|
|---|---|---|
| A（快速原型） | TypeScript + PixiJS/Canvas | 迭代最快，1-2周出可见成果 |
| B（长期） | C# + Unity UGUI | 与 03 包同语言，可直接引用 `StrategyGame.Core` |

**建议原型阶段用方案 A**，理由：验证玩法比性能重要，先跑起来。验证通过后再决定是否迁移到引擎。

如果选方案 A，通过 HTTP/WebSocket 调用 .NET 后端，或把 03 包的逻辑移植一份到 TS（**不推荐，会产生两份逻辑**，优先走后端调用）。

## 逐条需求

### R1 状态镜像

`GameStateStore` 从后端拉取 `WorldState` 快照，缓存为**只读**。所有 UI 组件从 store 读数据。

**UI 组件不得持有状态副本并自行修改。** 任何显示变化必须来自 store 的更新。

### R2 指令发送（唯一入口）

所有玩家操作都通过 `OrderSender` 发出一条 `Order`：

```typescript
OrderSender.send({
  actorType: 'Player',
  action: 'Dispatch',
  targetId: 3,
  secondaryTargetId: 1,
  amount: 5000
});
```

发送后等待 `ResolveResult`。**如果返回失败，必须显示 `Message`**——不能让玩家点了没反应。

### R3 战略地图

- 6 座城按 `AdjacentCityIds` 连线
- 每城显示：名称 / 归属色 / 人口 / 城防 / 是否首都
- 选中城池高亮，显示相邻城
- 悬停显示关键信息

### R4 双层视角入口

**这是本项目独特设计，必须在 UI 上明确体现。**

- 上帝视角：看到地图 + 全部势力信息，可下达宏观指令
- 亲自视角：选中自己 + 部队后，点击"亲征"进入

原型阶段**不实现**第一/三人称战斗（那是 05B 包），但要在 UI 上预留入口，让玩家知道这个方向存在。点击时提示"实时战斗将在后续版本开放"。

### R5 回合结算展示

每月 `Tick` 结束后，展示 `TurnResult`：

- 本月发生的关键事件（`EventRecord`）
- 关键数值变化（从 `StateDelta` 生成前后对比）
- 玩家可点击"继续"进入下月

### R6 人才任命面板

- 列出全部人才：姓名 / 专长 / 统率 / 政务 / 忠诚
- 显示当前岗位
- 支持：任命到岗、换任、赏赐（提升忠诚）

**这个面板是验证"用人"乐趣的核心，必须优先做好。**

## 验收标准（DoD）

### 硬性

- [ ] UI 层无任何 `WorldState` 字段写入代码
- [ ] 所有玩家操作经由 `OrderSender`，无旁路
- [ ] 指令失败时有明确视觉反馈（原因可见）
- [ ] 状态镜像为只读

### 功能

- [ ] 战略地图正确显示 6 城 3 势力，相邻连线正确
- [ ] 可完成完整回合：下令 → 结算 → 查看结果 → 下回合
- [ ] 人才面板可任命/换任/赏赐，数值变化可见
- [ ] 回合结算界面展示本月事件与数值变化
- [ ] 双层视角入口可见（亲征按钮存在，点击有明确提示）

### 边界

- [ ] UI 不做数值计算（抽查：搜索 UI 层是否有资源/伤害计算）
- [ ] UI 不判断指令合法性（全部等 `ResolveResult` 返回）

## 禁止事项

- 禁止在 UI 层做业务计算
- 禁止在 UI 层修改状态
- 禁止硬编码城池/势力/人才数据（一律从 `WorldState` 读）
- 禁止在前端写"如果粮不足就按钮置灰"之外的业务规则（合法性判断在Resolver，UI 只做友好的禁用提示）
- 禁止实现实时 3D 战斗（属于 05B 包）
