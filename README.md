# 我自己的游戏仓库

收集本人做/在做的游戏相关项目源码与设计文档。子目录：

- `xinyouzi` —— 大型战争策略游戏（主项目）。分层结构：设计规格层 / 内容数据层 / 规则内核层 / 智能体层 / 表现层（战略UI、实时战斗）/ 工程与验证层。多语言分块协作。
- `战争策略游戏` —— 战争策略游戏网页原型（TypeScript + Vite，含 src / python / docs / tests）。
- `火柴人军团3D` —— 火柴人军团 3D：战场模拟器 + 游戏数值设计 + 游戏美术。
- `大战略游戏剧情体系` —— 大型战争策略游戏的世界观 / 剧情 / 科技树等设定文档。

> 依赖目录（node_modules 等）不入库，需要时用各自项目的 package.json 重新安装。
