# 游戏数值设计工作流（适配 qwen-math-turbo 小上下文）

## 三个模型分别发什么
- **qwen3.8-max（文本主力）**：游戏剧情（时代总纲/科技树/分支/结局） + 美术代码（SVG / 像素 Canvas）
- **qwen3-vl（视觉，有额度）**：美术质检（截图挑比例/配色/风格）、参考图分析。不直接生图
- **qwen-math-turbo（数学，有额度）**：数值设计 —— 但它上下文小，必须拆分（见下）

## 为什么 math 要拆
math 模型上下文窗口小，一次塞不下整套兵种/公式/平衡计算。
解决思路：**拆成多个独立、自包含的小任务**，每个单独发一次 math 对话，结果粘到本文件底部"结果汇总区"，最后合并成完整数值文档。

## math 提示词铁律（小上下文保命）
1. 每次只算**一件事**，别让它写长文
2. 把输入参数**直接给数字**，别让它猜
3. 要求输出**紧凑结构化结果**（JSON 或表格），明确写"不要解释、不要铺垫"
4. 一个时代/一个阵营/一个公式 = 一次对话

## 拆分模块（每个模块=一次独立 math 对话）

### 模块1：数值基准框架
```
你是一个游戏数值设计师。请建立一套数值基准，只输出 JSON，不要任何解释。
规则：
- 总战力基准 = 100
- 1 个资源单位(金) = 10 战力换算
- 时代系数：古代1.0 / 中世纪1.5 / 近代3 / 现代6（攻防血都乘以该系数）
- 属性范围：攻击 5-50，防御 5-50，生命 20-200，造价 10-500金，训练时间 1-30秒
输出：{ "基准战力":100, "资源换算":10, "时代系数":{...}, "属性上下限":{...} }
```

### 模块2：单时代兵种属性（按时代分批，每次一个时代）
```
你是一个游戏数值设计师。请根据以下规则计算兵种属性，只输出 JSON，不要解释。
时代：{填 古代/中世纪/近代/现代}
时代系数：{填对应数字}
兵种清单与定位：
- 长矛兵：防御高(40)、攻击中(20)、血高(120)、造价低(30)、克制骑兵
- 弓箭手：攻击高(35)、防御低(15)、血中(70)、造价中(45)、被骑兵克制
- 战车/骑兵：机动高、造价高、克制弓箭手
请输出每个兵种：攻击/防御/生命/造价/训练时间/克制对象，纯 JSON。
```

### 模块3：伤害公式推导
```
你是一个游戏数值设计师。请推导战斗伤害公式，只输出公式和示例，不要长篇解释。
输入：攻击A、防御D、随机浮动±15%、兵种克制系数K(克制1.5/被克0.7/普通1.0)
要求：伤害 = (A - D*0.5) * K * 随机，下限为1，给出3个算例(攻50防20普通 / 攻35防15被克 / 攻20防40克制)。
输出：公式文本 + 算例表格。
```

### 模块4：资源产出曲线
```
你是一个游戏数值设计师。请设计资源(金/粮/木)每小时产出曲线，只输出表格，不要解释。
规则：
- 基础产出随时代翻倍：古代10/时，之后每时代×2
- 建筑每级+20%产出，最高10级
- 人口每100人+5产出
请输出：各时代基础产出表 + 建筑满级后产出表。
```

### 模块5：经济平衡校验
```
你是一个游戏数值设计师。校验以下数值是否失衡，只输出问题清单，不要废话。
输入（粘模块2/4的结果）：
- 若某兵种 造价/战力比 < 0.3 或 > 3，标"过强/过弱"
- 若资源产出增速 > 战力增速×2，标"经济膨胀"
- 若同代价下某兵种全面优于另一兵种，标"无意义选择"
输出：[{ "问题":"...", "建议":"..." }]
```

### 模块6：概率掉落表
```
你是一个游戏数值设计师。请设计战斗掉落概率表，只输出 JSON，不要解释。
规则：
- 总掉落率60%，普通资源70% / 稀有5% / 装备20% / 空白5%
- 难度系数：简单×0.8 普通×1 困难×1.3
- 保底：连续5次无装备，第6次必出
输出：{ "基础掉落":{...}, "难度修正":{...}, "保底规则":"..." }
```

## 用法
1. 把上面各模块提示词**逐个**发给 qwen-math-turbo（一次一个，别合并）
2. 把 math 返回的 JSON/表格**粘到上方汇总区对应位置**
3. 全部粘完后，把本文档发给我，我帮你合并、校验、整理成一份干净的数值设计文档（或 xlsx）
