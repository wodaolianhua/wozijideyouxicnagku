# 美术文档生成工作流（用 qwen3-vl 视觉模型）

## 用途
把你收集的参考图（历史建筑、兵器、服装、地图、截图等）丢给视觉模型 qwen3-vl，让它分析并生成一份**结构化美术设定文档**。这份文档后续可直接喂给文本模型(qwen3.8-max)去写 SVG / 像素图代码。

## 文件
- 提示词模板：`美术文档生成_VL提示词.txt`（直接用，或按需要微调）
- 调用工具：`E:/批量产出/游戏数值设计/call_bailian.py`（已支持视觉传图）

## 用法（接 call_bailian.py）
把参考图准备好，例如 `ref1.png`（可一次传多张，但脚本单次传一张，多张就多次调用并把结果合并）：

```
cd E:/批量产出/游戏数值设计
python call_bailian.py --model qwen3-vl-235b-a22b-thinking \
  --prompt-file ../游戏美术/美术文档生成_VL提示词.txt \
  --image "E:/你的参考图/ref1.png" \
  --out "E:/批量产出/游戏美术/美术文档_ref1.md"
```

多张参考图就换 `--image` 和 `--out` 各跑一次，最后把几份 `.md` 合并。

## 注意
- VL 模型**必须传图**才能生成美术文档。如果你暂时没有参考图、只想先写一份美术大纲，改用文本模型：
  `python call_bailian.py --model qwen3.8-max --prompt "写一份古代战争游戏美术设定文档，含风格/配色/元素清单/像素适配" --out 美术文档初稿.md`
- 生成后把美术文档发给我，我可以帮你转成 qwen3.8-max 能直接用的"美术代码生成提示词"（调色板变量、形状比例等）。
