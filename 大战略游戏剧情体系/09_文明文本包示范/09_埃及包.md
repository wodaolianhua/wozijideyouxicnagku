# 文明文本包示范九：埃及（尼罗河—红海）包

> 9 模块对齐《01_中原包》。本包承担全框架最极端的一次去中心化测试：**"成文法典"与"个人化统治"这两项"文明标配"在同一区同时存在了四千年**——按欧洲史分期，这一段应该叫"停滞"。本包的答卷是：**这不是停滞，是另一种时间观。**

---

## 一、文体总纲（本包）

第一人称是"我们与这条河的"——**尼罗河在本包不是地理条件，是唯一的同行者**，一切制度以"河水会做什么"为最终依据。**纪年不用王名，用"河水到第几次泛滥"**（"第七次大泛滥之后"＝一个可能被现代史学界判为公元前 1900 年的年份）。禁用一切"承平／中兴／盛世"式褒贬框架——**本包的历史观没有"复兴"这一栏，因为河不会退回去再回来**。全篇禁用"古老／原始／未开化"——那是把本包放在别人的时间轴上说话。

**本包最重要的一条产品化红线**：本区的"王"（法老）在叙事中同时是**神、人、符号三合一**，因此玩家对法老体系的任何反抗，文本上都不能被写成"亵渎"——只能写成"**与河谈判的方式不同**"。这是《05》去中心化原则在本包的机制化落地。

---

## 二、A 起源记忆（3 条，抽 1）

1. 《两河之间》——"我们的祖先不问这片土地能长什么，他们问：河水今年什么时候来、来几次、走的时候留下多少。**土地是河给的，不是神给的**——所以拜神不如记水位。"（本包独有：神权与水利互不统属，"水位记录官"（普罗奈特）职位独立于祭司体系，构成最早的"技术官僚"样本）

2. 《測量的名字》——"我们把土地量过，把河水量过，把影子量过。**量是我们的语言**——一个人说他可靠，意思是他说的话可以被复核。"（科技树影响：数学与测量类科技前置条件减一项；外交可信度判定在本包以"可否被复核"为唯一标准——**承诺若不可量化，本包视为未承诺**）

3. 《奥斯特拉的礼物》——"太阳神把身体给了我们：他的眼睛是太阳，他的骨头是土地，他的血是尼罗河。**所以我们不建神庙，我们建对齐太阳的石头**——那是给神的房子，也是给历法的仪器。"（建筑类科技叙事转译： pyramids 的功能在本包文本里首先是**测影与对历的仪器**，其次是陵墓，第三才是纪念物。**任何把金字塔写成"陵墓优先"的文本视为违规**）

## 三、B 核心创伤（2 条，抽 1；本区创伤**必须非玩家制造**）

1. 《改过的尺》——某朝为重赋税而缩短"肘"（长度单位），对百姓而言，**同样一臂地忽然多出了一寸**。创伤机制：本区文明的"度量衡变更"类政策永远伴随**民间自发复测传统**——每次官方改尺，埃及必出现一批"用旧尺说话的人"。这不是反抗暴政，是**拒绝让谎话变成常识**。系统实现：度量衡变更事件在本包自动附带"复测者"隐藏选项群。

2. 《第七次泛滥没有来》——某年预期的大泛滥未至，土地干裂，官方卜辞最初被判为神罚，后被证明是上游工程截流。创伤机制：本区文明"大型水利工程"类科技存在**不可逆风险**（下游国永远记得是谁动了水）；跨流域水利合作事件在本包永久附加"上游优先"猜疑链。**这条创伤禁止归因于玩家的殖民行为**——它必须由本区自身的历史造成。

## 五、D 时代色调微调（示范 3 条）

- 部落：火塘/霜 → **尼罗河的第一次改道**。第一句话从"神的数目"改为"水的数目"；首领就职夜的问题不是"帐篷放哪"（中原《第一晚》），而是"**这次洪水我们往高处搬，还是往低处守**"。

- 古典：宫殿批阅文件意象从泥板/竹简 → **莎草纸与水位刻度木**；"确定性"一段的排比改为"河有期、岁有候、田有籍、人有录"。

- 大航海：咸风进港的描写 → **运河闸门开启时咸淡水相撞的那条线**；"你站在码头上"改为"你站在闸口，看着两种水互相推挤三刻钟"。

## 七、F 悬停证言样本（跨 5 时代）

- 部落·第一次量地的绳结：「那根绳的结子还在。没人记得是谁打的，但它比这块地老。」
- 部落·上游截流的旧坝址：「坝拆了，河改了，村子没了。**三件事里只有两件留下痕迹。**」
- 古典·水位刻度木：「水退到第三道刻度那一年，他们说这是神迹。我数了刻度，那是第二十一年。」
- 古典·庙里的算式草稿：「上头是神的，下头是三角的。**草稿比正本诚实**。」
- 中世纪·水权争端的界碑：「碑的两面都刻着同一句话，**用了两套历法**。」
- 中世纪·神庙谷仓的门闩：「锁是防贼的，账是防神的——**账本比锁先坏**。」
- 大航海·闸口的咸淡水线：「两种水在闸口谁也不让谁。三刻钟之后混成一样，**然后各自又回去了**。」
- 大航海·运河公司的旧账：「他们挖的是河，养的是军队。**账上从来不写"公司"两个字**。」
- 工业·水坝淹没的村落名册：「名单上每个名字后面都有"迁"。**"迁"是唯一没有年份的字**。」
- 工业·灌渠管理的水位轮值表：「按田排，不按人排。**饿死的不是地主，是排错班的人**。」
- 冷战·不结盟宣言的签署地：「来的国家都比我们穷。**穷国家联合起来，地图上才有一块不是被分的**。」
- 统一·水权公约的草案页：「第一条：所有权是河的。第二条：使用权是我们的。第三条：**河不说话，仲裁是人的**。」

## 八、G 事件换装对照（《03》《07_03》本区适配示范）

| 原事件 | 原文明形态 | 埃及包形态 |
| :--- | :--- | :--- |
| 会说话的石头上的人（第一时代） | 无文字部族的"石之教" | **反转强化**：本区开局即"有石之教"（对影神庙）。玩家的"求知传统"在本区不是"请邻族来读"，而是"**教自己的祭司承认石头上的线画不是神意而是尺记**"——比对照包更激进的一步 |
| 老井结冰（第三时代） | 占卜者→学者测温／封锁 | 换为"**尼罗河不结冰**"：本区的异常是**水位异常**（该涨不涨／该退不退）。选项为"祭司祈雨／测量水位并改农时／照旧历行事"；第三选项在本区的代价文本是"**这次对了，但下一年不一定**"——**本区的正确答案是有保质期的** |
| 疫村的鼓（第三时代） | 禁令／拆鼓／编入历法 | 换为"**隔离与水源**"：疫村在上游。本区独有的第三选项"**改渠**"（把疫村的水道引开而非引人）——但改渠会改变下游水量，牵动水权（**本区第三选项必带外溢代价，这是它与其他包最大的不同**） |
| 伪造的圣髑（第四时代） | 承认／戳穿／官办圣髑 | 换为"**改历**"：有人拿出一套更准的历法，声称来自更古老的传统。选项为"沿用旧历／改用新历／新旧并行"。本区独有的第四态"改历但不改历名"（技术已换、符号未换）——**这是本区"承平"叙事的唯一合法入口，因为河不在乎你叫它什么** |
| 沉船岛交换（第五时代） | 平等交换／武力／离开 | 换为"**运河通行权**"：对方要的是运河的通过权，不是土地。选项为"卖通行权／拒绝／自己开一条"；第三选项在本区会触发"两河 → 红海"的水利竞赛叙事，**本区是 12 区中唯一把"运河"当作领土争端谈判对象的包** |
| 归乡者证词（第五时代） | 出版／封存／改编 | 译存为"**外乡水文志**"（对方河的水位记录）——本区执念的独有变体：中原关心对方制度，本包关心**对方的水**。改编选项在此地的后果文本是"**把他们的河说成我们的河**" |
| 广播事件（第九时代） | 取缔／解冻／公开 | 换为"**水情播报**"：非法电台被取缔的理由不是政治，而是"**它报了上游真的水位**"——公开水文数据在本区是最高级的政治行为。选项C的变体为"**官方逐日公布水位并允许质疑测量方法**"（本包的清算能力以"**可复核的公开**"计量，形式与中原的驳议可见度不同源） |

## 九、H 命名与避讳规范

1. **地名生成器**：以"河段 + 地貌 + 用途"三槽拼装（如"尼罗第四弯·淤田""东岸·石灰谷"）；**禁止使用现实埃及现代行政地名**，也不使用 1912 年后任何地名。

2. **人名**：法老名采用"王名 + 座号"两段式（"图特蒙图特"式构式，**避免现实已知法老名**）；普通人名取自"职业 + 特征"构式（如"测水的多"）。**禁用希腊化时期与现实人物名**。

3. **历法系统（产品化核心）**：本区纪年用"**泛滥次数**"。系统 UI 不显示"公元前 1900 年"，显示"**第 23 次大泛滥**"。这是全框架唯一使用非公元纪年的文明包，必须在 UI 层实现（非仅文本层）。

4. **宗教／族群词表**：涉现实宗教一律架空化。**本区法老体系不映射任何现实神祇**；本区文本中的"神"是"与河、与光、与王权签订契约的那一方"，不是任何现实神。

5. **不可屏蔽项声明**（本包产品化红线）：
   - **水位记录**不可被系统换算为"经济产出"或"资源储量"——请求换算返回固定文本："**水不是数，水是债。**"
   - **历法不可被玩家改写为已发生**——玩家可选择"改历"（影响未来），但历史记录中的既定年份不可被系统追溯修改（此为全框架唯一"历史不可改"的文明包规则，防止玩家用历法干预既往结局的兑付）

## 十一、本包设计说明

埃及包的设计挑战：如何让一个**被其他文明判为"停滞"的样本**，在全框架内获得与所有包完全对等的表现力。

**核心解法是"时间观不同源"**：
1. **河流不是条件，是同行者**——制度以"河水会做什么"为最终依据（中原是"工程的继承权"，两河是"水位读数"，埃及是"与河协商的契约"）。
2. **历法不可改写**——本区是唯一拥有"历史不可被玩家干预"规则的文明包，换来的是"河道不可谈判"的对等：你在外交上仍要面对玩不起时间优势的对手。
3. **神人符号三合一不可亵渎**——玩家对法老体系的反抗被文本化为"与河谈判的方式不同"，而非"反神"。这在机制层面对应"神庙书记可被质疑而系统不加惩罚"。

**本包与中原包的对照**：中原的"史官不可屏蔽"是**记忆的不可篡改**（谁做了什么，不能被改掉）；埃及的"水位不可屏蔽"是**外部条件的不可协商**（河做什么，不取决于谁当权）。两者合证《01_中原包》第十节那句话的深化版本——**12 区量产的难点不是写"不同的故事"，是允许"不同的不可协商"。**

**本包与两河包的对照**：两河以"城墙与刻度"认识世界（人工秩序优先），埃及以"河与泛滥"认识世界（自然节律优先）。两者在《02》科技树上互为"度量衡双极"，在《07/02》谈判系统中互为首选对手，在统一时代的水权提案上互补。
