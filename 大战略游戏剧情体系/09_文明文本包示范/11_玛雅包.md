# 文明文本包示范十一：玛雅（尤卡坦雨林—高盆地）包

> 11 模块对齐《01_中原包》。本包承担全框架**最硬的一次零门槛测试**：《02_科技树》的"原始文字"节点、《01_时代总纲》的"轴心时代"、《04_结局库》的"神权复兴"——三者都默认文明必须先有文字才能有哲学。这个文明**有哲学、有历法、有天文、有国家、有城市，却用了整个有记载历史的时间都没能发展出文字**。本包不是要论证它"本来也能发明文字"，而是让框架承认：**存在一条不经过文字抵达现代性的道路。**

**这是《05》去中心化原则第 4 条最彻底的一次落地，也是本项目目前风险最高的一份包。**

---

## 一、文体总纲（本包）

**第一人称是"我们"与"它们"严格分离**——本区的"我们"永远指**人**，"它们"指**神、山、树、石头、每一个"活着的或会动的非人存在"**。这是全框架唯一强制区分人/非人的文明包（对照其他包的第一人称几乎都是"我们+自然"的混用）。

**时间观以"圈"为单位**——不是圆（那是欧洲的线性进步观），是**石环上的刻度**。文本中提及历史时优先写"**那是第几个石环的记号之后**"。

**文体五条硬线**（全部为产品级约束，非风格建议）：

1. **禁用"没有文字所以没有历史"及任何同义暗示**（"他们的记忆只能口传""无法记录""因此落后"等一律禁止）——本区的记录方式是**刻在石上的数与形**，它记的是**数量、天数、名字、以及"发生过几次"**。本区文本里"历史"指的是"**发生过的事的次数与名字**"，而不是"被写下来的句子"。
2. **禁用"巫术"一词指称本区信仰**（本区的信仰是精确的天文观测与历法推算的产物，文本上以"**算**"和"**看**"呈现）。
3. **禁止出现"阿兹特克／印加／玛雅"三者混用**（三者时间线不同、政治形态不同、地理不同，混用即为欧洲中心式的"中美洲"笼统想象）。
4. **神名一律采用音译+意译双写**，且**本区神话不设"创世主神"**（本区的创世是"**上一次世界如何结束**"的循环叙事，不是一次性的起源事件）。
5. **本区"结束"不是失败**——本区的世界观中，上一次世界是被毁掉的，这次也会。所以"文明崩坏"结局在本区的文本**不得呈现为悲剧**（见 G 表。这是全框架唯一改变某结局情绪基调的文明包设计）。

## 二、A 起源记忆（3 条，抽 1）

1. 《石环上的那一天》——"我们不写句子。**我们在石头上刻数**——天数、次数、名字。刻完一块石头，我们知道一件事：这件事发生过，而且发生过几次。**句子会骗人，数不会。**"（系统实现：**本包无文字节点**。《02》科技树"原始文字"对本包显示为"**替代解锁：长计数与名号系统**"，二选一而非必须走文字。选本包路线时，文字类科技的前置条件全部替换为"石刻与名号传统"）

2. 《零的第一次》——"别的地区从一开始就会数，我们的祖先是从数到**零**开始的。**零不是一个数，零是'什么都没有'的意思**——想清楚这件事用了很多年。"（科技树影响：**数学类科技前置减两项**（零与数位），是天文学与历法精度的真实来源；外交可信度判定在本包以"**是否可计数**"为标准）

3. 《去年的雨和今年的雨》——"我们的祖先发现：今天下午的雨和去年同一天下午的雨，是**同一种雨**。不是因为它一样多，是因为它在**同一个位置回来的**。"（**本区天文观测的真正起点——本区的哲学核心是"重复中的同一"**，与中原的"工程的继承权"、两河的"水位读数"、埃及的"河协商契约"、波斯的"多样共处"、西非的"人即载体"构成**六种互不相同的文明认识论**）

## 三、B 核心创伤（2 条，抽 1；本区创伤**必须非玩家制造**）

1. 《被砍开的山》——雨林核心区的高地（低地雨林的发源与农业基础）被大规模伐作它用。创伤机制：本区文明"生态"类政策的**历史成功率 -25%**，且"雨林恢复"类工程在本区不是"环保议题"而是"**把山接回来**"——本区对"失去的森林"用的是**地形缺损**的语法，不是"污染"的语法（**污染是工业文明的本包对偶病，不是本区的**）。系统实现：伐林事件在本区永久附带"**泉水量变化**"作为可见后果（玩家会在三回合后看到泉变小）。

2. 《上一次世界的最后一日》——本区集体记忆中，上一次世界**不是被战争毁的，是被"用尽"毁的**（诸神收回他们的部分，让世界走到尽头）。创伤机制：本区文明"增长"类科技**自带一条天然的上限叙事**——它有本包独享的"**够用即止**"传统（见 C 表部落与统一两行）。**这条创伤禁止被改写为"我们本该发展更多"**——那是本包最核心的测试点。

## 五、D 时代色调微调（示范 3 条）

- 部落：霜/火塘/河冰 → **第一个旱季的水位下降**。第一句话从"神的数目"改为"**数到第几天了**"；首领就职夜的问题不是"帐篷放哪"，而是"**这次旱季，我们守泉还是守田**"。

- 古典：宫殿批阅文件 → **石刻与账（石板上的数串）**；"确定性"一段的排比改为"**天数定次序，石定位置，人定名**"。

- 大航海：海风气息 → **玻璃柜里的太阳石反光**；"你站在码头上"改为"**你站在展柜前，隔着玻璃看一块算过日子的石头，而它现在属于一个你无法通行的国家**"。

## 七、F 悬停证言样本（跨 5 时代）

- 部落·第一次刻数的那块石：「上面三个点。**没人记得那是什么，但都记得它比人老**。」
- 部落·望月台的四道刻痕：「这是雨季的数。这是旱季的数。**这四道是那两次旱的。**」
- 古典·石板上的数串与图符：「数的部分说明有多少，图的部分说明是谁。**连起来才是一件完整的事**。」
- 古典·没有文字的法庭：「证人刻了，法官核了，**结论是数出来的不是读出来的**。」
- 中世纪·迁城路上的界石：「城在旧山那边数的时候，还是这个数。**换了地方，没换算法**。」
- 中世纪·泉边的三级石阶：「第三级以下是雨季的水位。**我们不打水，我们看石阶**。」
- 大航海·玻璃柜里的太阳石：「它算过一整个国家的时间。现在它在说明别人的时间。」
- 大航海·玻璃柜外的记录本：「标签上没有我们的名字。**标签上只有编号**。」
- 启蒙·第一批教文字的学堂：「第一批孩子学会写自己的名字。**第二批学会写别人的**。」
- 工业·玻璃柜的两种锁：「柜上现在有两把锁，一把在展馆，一把在我们手里。**都不开**。」
- 工业·钟表与太阳历的对齐仪式：「那天我们把钟停了一刻钟。**太阳说没停**。」
- 冷战·归还议题的第一次会议：「他们说这是文物。我们说这是**账**。」
- 统一·够了之书的第一页：「第一页不写数字。**第一页写的是我们决定不再算了**。」

## 八、G 事件换装对照（《03》《07_03》本区适配示范）

| 原事件 | 原文明形态 | 玛雅包形态 |
| :--- | :--- | :--- |
| 会说话的石头上的人（第一时代） | 无文字部族的"石之教" | **本区为全框架的"石头之教"原型，但必须做关键反转**：玩家的"求知传统"在本区**不是"学会读石刻"**（因为没有字），而是"**学会看石头上的数与形代表了什么**"——**这是全框架最独特的一次科技解锁翻转：同一条石刻，在别的包是"文字的载体"，在本包是"数学的载体"** |
| 文字/知识的封锁（第三、四时代） | 焚书／禁书／改书 | **本区默认不生成此事件**（无书可焚）。若玩家试图封禁知识，事件文本转为"**移走石头**"——"他们没有烧书，他们把刻着数的那块石头搬走了。**那天之后，我们记得发生过，但记不得是谁**。"（回扣创伤逻辑：**本区的篡改只能是移除，不能是改写**——这是与西非包"改词"、中原包"改书"并列的第三种篡改形态：西非改内容，中原改文本，玛雅**移实物**） |
| 蛮族之问（第三时代） | 是否武力排斥 | 换为"**他们要的是林子**"：外来的扩张势力以"林地可耕"为理由。本区的核心问题不是"打不打"，是"**能不能守住一条不被砍的线**"——本区"防御"类建筑/结盟效果在此事件中替代"军事"类效果生效（**全框架唯一防御手段被重新定义的文明包**） |
| 帝国扩张（第五、六时代） | 领土整合 | 换为"**城邦联盟 vs 高地控制**"：本区古典时代为**城邦联盟**（无统一帝国），轴心时代的整合选项不是"并吞"而是"**共用历法**"（对齐历法即事实上的整合，**本区是全框架唯一"历法统一可替代政治统一"的文明包**） |
| 殖民者契约（第五时代） | 签署/修改/拒绝 | **本区默认不生成**（本区不是殖民者）。生成的是"**被殖民**"版本：选项为"配合/抵制/假装配合"；第三选项在本区的代价是"**他们真的以为你配合了，于是开始砍**"（对照南洋包的"签订"，本区的"假装"是一种更坏的选择） |
| 那个按钮／极限手段（第八时代） | 核战/总体战 | 换为"**毁林事件**"：以"烧掉这片林子让对方失去补给"为选项。**本区的这一选项必须被文本明确标注为"我们最想选的，其实是我们最不能承认的"**（回扣创伤 1）——本区"底线"类修改的**触发点不是道德，是"你怎么向山解释"** |
| 文明崩坏（结局五） | 悲凉/追悼/考古视角 | **本区是全框架唯一改变此结局情绪基线的文明包**：文本**不呈现为"它结束了"**，而呈现为"**它完成了一个轮次**"。仍然写废墟、仍然写"孩子捡到一枚锈掉的芯片"，但**旁白不谴责**。依据：创伤 2（上一次世界也是被毁的，毁是循环的一部分）。**注意：这不取消代价，代价照写；只是叙述者不站在废墟外哭** |
| 广播事件（第九时代） | 取缔／解冻／公开 | 换为"**刻石**"：有人要在公共场所刻一段"我们自己的历史"（对照印尼/印度的公开历史刻石传统，此处为架空变体）。选项为"禁止/准刻/官方也刻一段"；**本区的"清算能力"计量方式：政府是否愿意把记录权交给别人**（与埃及的"可复核的公开"、波斯的多版本并置构成本框架三种清算形态） |

## 九、H 命名与避讳规范

1. **地名生成器**：以"地形特征 + 水源类型 + 聚落规模"三槽拼装（如"**高盆·三泉·石城**"）；**禁止使用现实尤卡坦/危地马拉/墨西哥行政区名**，使用架空区名（"低地雨林区""高盆区""白沙区"）。

2. **人名**：本区人名**不使用"名+姓"结构**，使用"**日期—名号**"制（如"第三百日的持矛者"）——因为本区标识人的方式是"你在哪一天被取名"。

3. **神名双写规范**：所有神名必须**音译 + 意译并列**（如"雨神：恰克／'落在石上的那一位'"）。**意译必须含一个具体的自然动作**，不得译为抽象概念。

4. **本区刻文规范（产品化）**：本区的"文本"是**刻在石上的图形+数字**。**美术与 UI 必须能表现"石刻图形"，且这些图形不构成可读语言**——玩家应看到"这是一段记录"，但读不出字。**这是本包最特殊的技术需求，须在技术方案中提前立项**（不能先用乱码字形凑合，那会把本包变成"不识字"的刻板印象）。

5. **"巫术"一词禁用清单**（本包最重要的一条产品化红线）：本包全部文本**禁止使用"巫术/魔法/迷信"描述本区信仰实践**。凡文本出现，一律替换为本区专属表述："**对天数与位置的观测推算**""**与山的协商**"。（理由：本区的历法精度是**真实的计算成果**——用"巫术"描述它，是对一个数学传统的贬义化。**这是《05》去中心化原则在本包最容易被违反、也最必须守住的一条**。）

6. **不可屏蔽项声明**：
   - **天数记录不可被系统换算为"资源"或"进度"**（请求换算返回固定文本："**那是天数，不是数**"）
   - **石刻实物不可被系统判定为"无用文物"**（文物归还议题在本区为强制事件，不可跳过）

## 十一、本包设计说明

玛雅包的设计挑战：如何让一个**在"文字"这一项上全程缺席的文明**，在全框架内获得与所有包完全对等的表现力，同时不让"缺席文字"被读成"低等"。

**核心解法是"缺席是一种立场，不是一个缺陷"**：
1. **记录的对象不同**——别的包记录"说了什么"，本包记录"**发生了几次、是谁、哪一天**"。这不是记录能力的降级，是**记录目的的差异**（本区要防的失真是"名字被抹掉"，不是"语句被曲解"）。
2. **篡改成本谱系的第三种形态**——中原是"改文本"、西非是"改词"、本区是"**移实物**"。三者各有各的代价，本区最贵：**因为移走的不是话，是事本身。**
3. **结局五的情绪翻转**——本包不删代价，但换叙述者的位置。**这是本项目目前唯一一次修改主线结局情绪基调的操作，须经制作人确认**（详见下方"待裁定"）。

**本包与西非包的对照**：西非证明了"记录可以不依赖物质载体"（人即载体），玛雅证明了"**记录可以依赖物质载体而不依赖文字**"（石即载体）。两者合证《01_中原包》第十节的深化：**12 区量产的难点不是写"不同的故事"，是允许"不同的必备项"。** 中原的"不可屏蔽项"是史官（记忆不可篡改），埃及的是水位（外部条件不可协商），波斯的是多语原文（不可合并），玛雅的是石刻实物（不可判为无用）——**四种"不可协商"，四种完全不同的系统实现。**
