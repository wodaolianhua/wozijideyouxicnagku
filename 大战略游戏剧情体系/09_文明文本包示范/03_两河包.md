# 文明文本包示范三：两河（底格里斯—幼发拉底）包

> 8 模块结构对齐《01_中原包》。本包示范**最古老的都市文明**如何接入框架：它的特殊性不在"早"，而在"一切制度都是第一份"——法典、学校、税收、灭世记忆全是人类初稿，初稿的文体特征是"刚发明的东西被当作天经地义"。

---

## 一、文体总纲

第一人称是"城的"而非"国的"——本包文明认同的极限尺度是城墙之内；计量以"水位年名"（每年以当年要事命名，如"某王筑墙之年"）——**编年的原始形态是日历化的史书**，本包所有时间表述自带史官性。泥土意象配额最高：泥板、泥砖、泥表、人出自泥（禁用木/纸类载体隐喻）。

## 二、A 起源记忆（3 条，抽 1）

1. 《泥自水来》——"神用河泥捏了我们，就像我们捏砖。所以我们欠水两层：一层在身体里，一层在墙里。"（灌溉科技在本包附带"身体—城墙"双关语料；洪患事件文本全部走"归还"意象而非"惩罚"）
2. 《第一份抄书》——"学校的第一课不是读书，是把老师的话原样按进泥里。按得最像的人，死后名字进了砖。"（官僚选拔制在本包以"泥板书舍出身"为社会流动通道，科举路径的变体接口）
3. 《十日洪水账》——灭世神话版本：神淹世界前，一位城民偷偷记了十天水位账，账板随漂流木幸存。"我们不靠神谕知罪，我们靠水位读数。"（**本包独有的世俗科学种子叙事**——与主线"天文历法"节点直接咬合：占卜与观测在同一个祭司手里，这是两河特色）

## 三、B 核心创伤（2 条，抽 1；均非玩家制造）

1. 《盐进田年表》——持续灌溉导致土壤盐碱化，小麦退向大麦、大麦退向耐盐草，八百年逐田记录的败退账。创伤机制：本包文明"农业最大化"政策的边际收益曲线自带 -20% 长期修正（**所有文明里唯一把生态债务写成文明记忆的**——与《07_03》事件"老井结冰"类同感应，本包版本：田头界石逐年向河移，孩子在界石上刻新位置，界石刻满即弃田）
2. 《城破的图书馆》——外族破城焚泥板（泥板遇火反而部分烧结幸存，真创伤是**书架散佚而非材料毁灭**）。创伤机制：知识封锁类政策在本包历史成功率额外 -15%（低于中原包的焚书教训——"火帮我们把字烧得更硬"），且本包文明所有"存档"类行为附带"备份三处"的仪式化文本。

## 四、C 当代执念（10 时代全表）

| 时代 | 执念 | 外交接口 |
| :--- | :--- | :--- |
| 部落 | 让洪水年名连成一条不断代的水账 | 对草原系"无账可查"的外交默认存疑（对照草原包《白毛风》，两包互为"记账者/记事者"偏见链） |
| 古典 | 法典刻上石柱才算数（成文的炫耀性） | 与中原包谈判必争"铸刑鼎还是立石柱"——两种成文法的公开性之争 |
| 轴心 | 观测与占卜能不能分家 | 哲学事件以"水位派对征兆派"内部论战呈现（本区独有无神论萌芽路径） |
| 中世纪 | 商队路线上的驿栈联盟主权 | 无帝国执念，商业网络自治传统（行会变体="万商栈约"） |
| 大航海 | 我们是内陆人，海是别人带来的税 | 不参与殖民，但自动成为新航路"陆桥崩盘"的受害者事件链主角（殖民遗产值计算中本区恒为被抽取方，除非玩家走通"驿栈联盟"独立线） |
| 启蒙 | 法典可改，石柱不可搬——那谁是石柱 | 宪政事件以"换柱之争"呈现：成文法的物质载体成为主权隐喻 |
| 工业 | 油井：我们守了一千年水账，现在地下冒黑水 | "盐进田"创伤自动转译为"黑水进田"——本包工业线环保事件强度 +25% |
| 大战 | 战区内的古城遗址被双方同时炮击 | "备份三处"创伤在炮火下成为生存策略：本包战争事件独有"文物疏散线" |
| 冷战 | 石油主权与管道过境费的第几手 | 不结盟路线附加"管道多边"独有子链 |
| 统一 | 年名制：世界要不要一个共同的"今年叫什么" | "全球治理架构"事件在本包附加独有议题《历法条款》——统一的时间叙事权之争 |

## 五、D 时代色调微调（示范 3 条）

- 部落：霜/河冰起兴 → "水位标尺上的新刻痕比日历诚实"。
- 古典：竹简批阅 → 泥板改写（湿泥重按的"啪"声为专属感官锚点）。
- 工业：火车＝"不吃草的铁马"在本包为"比驿队更不守水约的黑蛇"（输油管意象）。

## 七、F 悬停证言样本

- 古典·石柱法典：「48 条，3 条涂改过。涂改处的楔形最深。」
- 轴心·水位标尺：「神学在读天，他在读数。他们用的是同一根绳子。」
- 中世纪·商队驿栈：「栈约第八条：骗谁不能骗下一季的水。」
- 工业·第一口油井：「黑水冒出来那天，水位账断了一年——没人敢记。」

## 八、G 事件换装对照

| 原事件 | 两河包形态 |
| :--- | :--- |
| 成文法典（主线二） | "石柱还是泥板"之争：公开性（石柱）对修订便利（泥板）——本区独有第四选项"双轨制"（石柱示众、泥板留改），代价为法统分裂隐患 |
| 知识的边界（主线五） | "给后来人吵架用"的空白栏制度——审查事件在本区变成"空白栏宽度之争"（审查者要求加宽=删除留痕的合法性） |
| 黑死病（主线四） | 水路隔离：本区独有"封闸而非封城"选项——断运河即断疫，粮食代价极高，与"盐进田"账联动 |
| 广播事件（主线九） | "泥板电台"：广播稿被听众同步刻成泥板存档——**不可屏蔽红线在本区表现为"刻痕不可销毁"**（同中原包史官、草原包歌，三区三形态） |

## 九、H 命名与避讳规范

1. 人名取"神+动词/名词"构式（架空化：神名池自造 12 个，禁真神名）；年名池 60 条按事件系统自动生成为"动词+宾语+施事"。
2. 洪水、祭坛、巫术词汇一律架空拼写，禁止与任何现存宗教经典术语同形。
3. **不可屏蔽项**：水位账（历法事件档案）与法典涂改痕——玩家政策不能删除，只能在泥板上再涂改，**而涂改深度本身就是证据**。本包对"修改历史"的机制表达：不是抹掉，是留下抹掉的形状。

## 十、验收

C 表接口齐 10 条；B 双创伤均为"慢性账目"型（本包创伤特征=可计量的衰减，区别于草原的突发、中原的人祸）；G 表含第四选项 1 条（双轨制）；H 含"涂改即证据"声明。本包证明：**最古文明接入框架的方式不是"原始版中原"，而是把"第一份"本身做成机制。**
