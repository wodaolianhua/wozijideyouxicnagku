# 第二段·纪元十三：相遇纪元 —— 详细剧情脚本

> 上游依据：《08_10_星际纪元卷规格书》第二节、第三节、第四节。本脚本不修改任何第一段原文。
> **属性声明**：随本文档自带（依《00》规则二惯例，待第二段四纪元全部落成后统一并入《10》总表）。
> **调参提示**：数值为试算值，落地前须回《12_数值设计规范》套五条铁律。
> **本纪元是第二段难度峰值**，也是《08/10》第二条专属事件链《四十二光年》的所在纪元。

## 背景叙事

四十二年是一个数字，但船上的孩子不这么算。

他们出生在减速舱的第一段航程里，十二岁时第一次看见舷窗外固定的星点，二十四岁时参与了第一次自治投票，三十六岁时他们中的第一批人开始争论一件你无法理解的事：

**"我们算不算人类？"**

这不是哲学问题。这是一个每天都要处理的行政问题——因为船上的医疗分类表里只有 11 个标准人类体型，而出生在船上的孩子，有 4% 不在任何一栏里。

你收到他们的第一份正式文件时，正在读地球日报的第十九版。你已习惯这种阅读顺序：先看远方的，再看近处的。**但这份文件的第一行就让你意识到，顺序反了。**

文件的开头写着一句话，是这次接触使团发出的那份介绍词的第四十二世孙的改写版：

> "**你们描述自己的时候用了'人类'这个词。我们没有这个词。**我们对应它的概念里，**有一个位置是空的，等着被填。**"

**那个位置是空的——他们还没决定要不要填。**

你的舰队在四十二年前出发。它现在停在离地球四十二光年的地方，屏幕上有一份正在缓慢成形的文本，翻译器显示置信度 61%（这是你三年前观测换来的那 61%）。

你可以现在靠岸。

**在靠岸之前，你必须回答一个问题：你自己对这个"空位"的理解，能正确传达给船上一万一千个从未见过海的人吗？**

## 三个主线任务

### 主线一：空位

**任务目标**：在靠岸前确定"人类"这个概念在外星语境中的对应物。四个候选定义（详见下文）。

**叙事驱动**：这是全第二段最难的机制设计，因为它**没有正确答案，而游戏会明说这一点**。

外星方的对应概念（系统称"**并列位**"）具有一个特征：**它不为单个个体保留位置**。个体的生死与更替在这个概念里不是"死亡"，是"**归还**"——用"死亡"翻译它会立刻产生误解，用"轮回"翻译它也会。

翻译组吵了两年。语言学家给出的结论是：**这个概念的外文定义里，"你"这个词在两千年里被改写了一次，现在它指的不是一个人，是一段被延续的关系。**

四个候选定义：

| 定义 | 内容 | 若采用会怎样 |
| :--- | :--- | :--- |
| **A. 对等映射** | 承认"我们找不到对应词"，并明确告知对方"我们选择用最接近的词指称你们，同时知道它不准" | 最诚实，也最慢。对方会认为这是一种**能力的边界声明**，多数智识型外星个体对此评价正面 |
| **B. 功能映射** | 选定一个功能上最接近的词，宣布"这就是你们" | 效率最高，也最危险。**一旦官方宣布，纠正就不存在了**——此后所有翻译都必须从这个错词出发 |
| **C. 保留空白** | 在人类的正式文本中，外星方名称永远留空，不填词 | 唯一保留"他者镜像 = 不可比"可能的路线。**但地球的语言系统会因此留下一万个语法空位**——这会产生实际的信息损失（大量可表达的概念变成不可表达） |
| **D. 交替使用** | 承认无对应词，并创造一个"折中复合词"（发音取自双方，语义只在一半意义上成立） | 最聪明也最脆弱。它在文本上极好读，但**它的意思无法被回译**——当对方用这个词的时候，它指的是全义的一半 |

**关键设计**：这四个选项**不构成"最优化"关系**。它们是**四种不同的风险**：

- A 选"能力边界" → 对方可能觉得人类**没有能力理解**（这是最严重的误读，且它将由对方自己补完）
- B 选"错误等义词" → 人类之后的所有星际文本都基于一个错词，且**这个错词会成为人类自己的官方语言**
- C 选"留空" → 地球的知识系统在 100 年内因表达缺口而损失一批概念（**这是本纪元唯一的"技术性损失"**）
- D 选"折中复合词" → 人类与对方之间会产生**一种双方都无法完整听到的共同语言**

**红线校验（《08/10》红线 3）**：本主线的**所有四个选项都是误解的制造者**。**没有一个选项能避免误解，只决定误解的形状。** 游戏不会告诉你哪个误解最无害。

**机制关联**：
- 本选择生成"他者镜像"的**第一性特征**：A/D 倾向"可比"，C 倾向"不可比"，B 直接制造"错误理解"
- "接触语法"（纪元十一）**不提供正确答案**，但**会改变各选项的初始可用性**：技术性接触语法下 B 初始支持度 +25%（它最喜欢"选一个、宣布"），生活性下 C +25%（它最容忍"暂时不填"）

### 主线二：《他们不喜欢我们》（本纪元触发，无抉择）

> **这是《08/10》指定的专属事件链，纪元十二末尾开始播放，本纪元完成结算。**

**为什么它在本纪元完成结算**：纪元十二时你只有猜测，本纪元你有了**数据**。

对方正式提交了一份对人类文明的整体评价。**这份评价的每一条都以人类自己的历史为依据。**

以下是它的一部分（内容随玩家第一段与第二段的选择动态生成，此处为示例）：

> **"你们宣称自己重视契约。我们注意到：你们的最大规模互信崩溃发生在一次共同宣布之后——你们把一项分歧当成了共识。**
>
> **你们宣称自己是多种文明。我们注意到：你们的技术传播速度与你们的贸易增长速度之比是 47:1。这个比值在你们的历史上从未改变过。**
>
> **我们不判断你们是否善良。我们只报告一个数据：你们描述自己的方式，与你们行动的方式，之间的平均偏差是 3.7 倍。**
>
> **这不是责备。这是我们理解你们的唯一方法。**"

**全段无玩家抉择，不可跳过、不可加速。** 这份文件是第二段全程最重要的文本，且**在六个结局中全部有效**。

**机制关联**：
- 此评价的严厉程度**与"接触语法"的对应态正相关**（技术性→偏差更大；生活性→偏差最小，因为生活性语法的自我描述本身就接近生活）
- **它不改变任何数值**。这是刻意的：《12》铁律 5 要求结局用档不用值，而这里连档都不给——**它只是让玩家知道自己被看见了**

### 主线三：第一份双向文本

**任务目标**：在完全靠岸之前，交换第一份非对称的完整文本——地球发出全量介绍（长度由纪元十一的"介绍词"决定），对方回送一份**同等长度**的自述。

**叙事驱动**：这份交换的真正戏剧性在于：**对方回送的那份，自述长度与你的介绍词几乎完全一致。**

**不是巧合。** 对方在收到你的文本后，用同样的长度回了一份。

后来的翻译组才想明白这意味着什么——**他们在模仿你的格式。** 一个刚认识四十二小时的文明，选择了"用对方的方式介绍自己"作为第一次回应。这不是外交礼节，是**一种表态：我们看到了你描述自己的方式，我们决定用同一种方式回。**

而这份"用同样的方式回"造成了一个 200 年都没解决的技术问题：**他们那份文本里，有 12% 的段落无法映射到任何人类概念**，而这些段落在他们的语境里是**最基础的部分**（相当于人类的"一""人""生""死"这类概念的位置）。

**你的选择**：

#### 选项A：立即靠岸，用"翻译不完整"作为正式外交前提

**即时后果**：人类与对方的所有后续接触都在"我们知道你们 12% 的基础词汇我们译不出"这个前提下进行。这**会在地球引发一场关于"我们是否有资格代表人类"的争论**——因为"翻译不了"可能被解读为"我们不是同一种生物"。

**长期影响**：为"他者镜像 = **不可比**"提供最强支撑，且**这是唯一与《08/10》结局四《人类的定义》完全兼容的路线**。代价：地球的星际事务在 100 年内进展缓慢。

#### 选项B：先在轨道上生活二十年，用共同生活补齐翻译

**即时后果**：船队与对方建立长期共居关系。这需要 20 年（双方各出对等人数），且需要玩家处理一个新的问题：**共居意味着双方互相观察，而观察会产生模仿，模仿会产生边界模糊。**

**长期影响**：翻译率提升至约 80%，"他者镜像"进入"**相同**"或"**相左**"的判定区间（不可比可能性永久关闭）。这是最稳妥的路线，也是**唯一能让第二段"和解"发生的路线**——**但它依然不是"接触即和解"：二十年后双方关系良好，但那个 12% 依然译不出。**（这是本纪元最重要的一句话，也是《08/10》红线 3 的最终注脚）

#### 选项C：以地球为唯一交点，不共居，只在双方首都互驻

**即时后果**：最保守，也最符合第一段"统一地球"的政治逻辑。**但它在宇宙尺度上是个小规模方案**——每次交流都要跨越四十二光年，且每一代人都要重新学习已经归档的翻译。

**长期影响**：翻译率停滞在 61%，**但"他者镜像"的判定周期被拉得非常长**——它的最终形态可能在第二段结束时仍未确定。**这是唯一会让"他者镜像"在结局中保持问号的路线。**

## 两个独有剧情分支事件

### 分支事件一：《关系定义之争》

**触发条件**：主线二完成后。对方提出一个"关系名称"要求：它们希望地球与它们之间有一个正式的关系称谓，并且**要求由地球决定名称**。

这个要求在政治上是一次精妙的测试：

**接受对方给出的名称** → 人类被归入对方的社会关系图谱（无论名称多好听，"某某的成员"这个结构本身是包含性的）

**自己定义名称** → 人类独立，但可能被解读为拒绝承认对方的"给予"

**协商定义** → 耗时且脆弱

#### 选项A：接受对方的名称

**即时后果**：全球舆论分裂。反对者认为这是"入伙"，支持者认为这是"务实"。**你实际上交出的是"我们之间的关系的定义权"，而这一点在档案里会写得很清楚。**

**长期影响**："他者镜像"判定为"**相左**"（因为它把你的定义与它的定义摆在同一结构里，而这个结构是它设计的）。这条路线通向《08/10》结局一《星海回声》——**"人类学会了对方的语言，却发现对方早就学会了人类的"**，但机制上是"人类接受了对方的坐标系"。

#### 选项B：自己定义名称

**即时后果**：对方接受了。**但它在四十二光年之外做了一件人类没有预料到的事：它开始使用人类给它的名称来称呼自己**——包括在所有对外通讯中。

这个行为的重量在第六个月才被完全理解：**你没有给它命名，你承认了它。**

**长期影响**："他者镜像"判定为"**相同**"（或极接近）。这是最暖的路线，也是**最危险的一条**：它让人类第一次把"我们"扩展到地球之外，而这**恰恰是纪元十四的核心问题**。**如果人类在纪元十三已经学会了说"我们包括他们"，那么纪元十四"统一还成立吗"这个问题就有了答案——而这个答案是"成立，但范围变了"。**

#### 选项C：协商定义，产出一份双语的联合声明

**即时后果**：耗时 11 个月。文本最终是一份两份声明并排的公告。

**长期影响**：这是唯一**让"他者镜像"保持"不可比"可能**的选项——因为联合声明在结构上承认了"我们各自的说法都不足以覆盖这件事"。代价：地球在对外表述上永远要带一个括号。

### 分支事件二：《第一件他们不告诉我们的事》

**触发条件**：主线三任意路线进行中。

### 一个不设选项的事件（第二种"无抉择"设计）

对方**主动**告知人类一件它们的技术原理，并说明"这不是秘密，只是我们选择现在说"。

它被解读为善意。**但三年后，地球才发现它的实际用途完全不同于人类的预期**——它不用于通信、不用于能源、不用于任何军事用途。

**三年后的真相**：那个技术的唯一用途是**个人隐私保护**。

对方把这个技术给了地球，因为对方**认为地球正在进入一个大规模监控的社会**。

**玩家无选项。** 但系统会做一件事：**它把这个事件标记为"对方评价人类的方式"的一条实证**，并在纪元十四结算时引用。引用形式是一句话（不带数值）：

> "**它们比我们更早看出我们正在变成什么。**"

**设计意图**：这是《08/10》红线 1 的最彻底执行——**外星不是更善良的前辈，也不是更强大的邻居，它是一个"已经经历过那件事的邻居"**。而它对人类的第一件赠礼，恰好是提醒人类不要变成它自己。**这份礼物的尴尬程度是设计目标。**

## 专属事件链：《四十二光年》（本纪元核心纯叙事段，无抉择）

> **《08/10》指定的第二段专属事件链 3。** 发生于船队抵达途中。全程玩家无任何选择。

**形式**：**改写数据源。** 这段不使用 3D 场景，而使用**船队的公共档案文本**——航行日志、公议记录、一份流传的《我们这一支的家谱》。

**内容**（110 分钟游戏时长，全部为"档案文本 + 缓慢移动的时间轴"）：

档案展示了船队四十二年航程中**从未向地球汇报过的一切**：

- 第 6 年：船上的第一次食物危机。配给委员会决定"按贡献量分配"。**决策记录里有 3 票反对**，反对者认为"孩子不该因为还没干活就饿着"。
- 第 11 年：一批人要求"我们不应该只学地球的语言，应该学我们自己的"。他们要求表决。**表决通过了，但没通过提案**——他们被要求"先做出成果再申请承认"。
- 第 19 年：船上出生了第一批"**从未见过地球的白痴孩子**"（这是档案原文的用词）。他们中的一个人在日记里写："**我查了记录，我的祖父母出生在地球上。我没见过。我连想象都没试过，因为那没有用。**"
- 第 28 年：一次权力斗争。**没有人叛变**——是有人提出"我们应该选一个能管事的人"，而另一方说"我们应该先试三套方案"。**结果是三套方案全试了，三套都失败了，然后他们又试了第四套。**
- 第 33 年：**有一群人拒绝执行船队的命令**，理由是"我们代表的是我们村来的那批人"。他们被隔离了 8 个月，之后没有受到任何处罚。**档案原文记了一句："我们把这件事写下来，是因为我们不知道它算不算发生过。"**
- 第 41 年：船队收到地球的最后一批指令（其中一部分内容你完全不记得发过——**因为那是候补政府发的，不是你**）。**他们执行了其中的 70%，理由是"那不是我们认识的那个人下的"。**

**然后是最后一段**（第 42 年，抵达前 3 个月）：

一份公议提案，署名人数 8,400（占船队当时总人口的 71%）：

> "**我们请求在我们见到任何地球人之前，先由我们自己决定：我们希望以什么身份见他。**"

**提案获得通过。** 通过之后的三天里，船队表决确定了抵达时的礼仪。

**画面到此为止。** 没有落到"他们见到了对方"。**这一段结束的方式是：他们还没见到，你就失去了对他们的一部分了解。**

**机制关联**：
- 玩家在主界面会得到一个**"地球档案库未覆盖"的提示**——这是全游戏唯一一处"你的存档缺了一块"的 UI 设计（提示文本固定为："**你在那三年里不在，他们自己过了那三年。**"）
- 这份档案**是"他者镜像"判定的核心输入**（判定的不是对方文明，而是**人类在四十二年后变成了什么**）
- **它不产生任何数值**。它是第二段的情绪底座

## 时代收束事件：靠岸

相遇纪元结束时不放传统的过场。游戏播放的是**《四十二光年》档案的最后一段朗读**——就是那份 8,400 人的提案，朗读者是船上的一个孩子，**他念到"在我们见到任何地球人之前"时停了一下，然后念完**。

然后游戏给出全第二段最重要的一句提示，只有一行，不做任何解释：

> "**他们准备好了。你没有。**"

时代结算随之开始。

## 时代结算：两项属性确定

### 一、他者镜像（三态判定，本纪元核心）

**判定输入**：《四十二光年》档案（人类四十二年变成了什么）× 主线一（人类用什么词描述对方）× 主线三（是否共居）× 分支一（关系名称由谁定义）

**三态及其含义**（这是全第二段最重要的机制，也是《08/10》红线 1 的落地形式）：

| 态 | 判定条件 | 含义 |
| :--- | :--- | :--- |
| **相同** | 分支一 B + 航线 A/C + 四十二光年档案未出现"身份争议" | 对方选择模仿人类的自我描述方式。**这不是巧合，是表态** |
| **相左** | 分支一 A + 对方"关系定义"结构占优 | 对方给出了一个与人类不同但同样自洽的答案。**两个答案并列存在，不存在谁对** |
| **不可比** | 主线一 C（保留空白）+ 分支一 C（联合声明） | 双方各自的自述都无法覆盖对方。**这不代表对方更复杂或更简单，只代表"我们各自只有一半的词"** |

**红线校验**：《08/10》红线 1 的最终校验点——**三种判定结果中，没有一种是"对方更先进"或"对方更善良"**。"相同"不等于"对方模仿了我们所以对方低一等"，"不可比"不等于"对方更神秘所以更高级"。**系统不在结局文本中使用任何带等级判断的措辞描述对方文明。**

### 二、返航权（形态确定）

- 来自纪元十二的宪法草案 + 本纪元的共居选择
- **关键变化**：**返航权在此刻从"法律问题"变成"事实问题"**——地球与船队已经分开了四十二年，"返航"在物理上需要地球有能力接住 8,400 个从未见过海的人。**如果地球在纪元十二的安置政策中选择了"无特殊政策"（留下人群稳定度极低），地球本身可能无力接住他们。** 这条联动是刻意的：**你在四十二年前对留下的人做的决定，决定了他们能不能回到你身边。**
