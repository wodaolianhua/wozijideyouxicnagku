# 数值设计规范

> 读者：数值策划、程序、AI 行为设计。
> 本文档是《05_叙事基调建议》附录节「跨时代数值的落地衰减原则」的**独立化与展开**——原附录只有 5 条原则，散落在叙事宪法末尾、数值岗按图索骥不到，故独立成文并补全执行细则。
> **本文档不改任何叙事原文，只规定"《06》里写的那些百分比，在游戏里到底怎么算"。**

---

## 零、为什么需要这份文档

《06 时代剧情脚本》给出的修正值（如"外交声誉永久 -20%""科技研发速度 +15%"）是**为叙事示范写的**，普遍偏重。直接搬进代码会立刻崩：

- **修正值溢出**：一个选项影响三四个时代，每代 20–50%，线性叠加后单时代累计可达 300%+，后期任何选择都无效
- **玩家感知麻木**：所有选择都变成"+15% 这个、+20% 那个"，选择不再有分量
- **后期失衡**：早期的小选择滚成后期的主导变量，玩家早期的一次微选择决定终局，且他不知道

所以《05》定了 5 条衰减原则作为铁律，《00》阅读路线给数值岗的顺序是「**05 附节 → 08/01 → 06 各时代结算节 → 04 触发条件**」，核心意思是：**先定衰减管线，再进数值表**。

本文档把这条管线展开为可直接编码的规则。

---

## 一、五条铁律（不可违背）

### 1. 半衰期衰减

**任何跨时代修正值，每跨越一个时代自动衰减 40%。**

- 衰减系数 **0.6**（保留 60%）
- 例：`-30%` → 跨 1 代 `-18%` → 跨 2 代 `-10.8%` → 跨 3 代 `-6.5%`

**实现**：`effective = base × 0.6^generations_passed`

**设计意图**：让"遥远的选择"仍有可感知的回声（玩家在第十时代还能感到第三时代那次背信），但绝不永久统治游戏。

**注意**：这条只作用于**连续型修正值**（百分比加减）。布尔门闩（路线锁定）不衰减——见第 3 条。

### 2. 同类不叠加

**同一维度的多个标记只取最强值 + 其余值 × 25%。**

- 例：玩家在轴心时代拿到 `+30% 反思类`，又在启蒙时代拿到 `+20% 反思类` → 实际 `+30% + 20%×25% = +35%`
- 若有 n 个同类标记：`effective = max + (sum_of_others) × 0.25`

**设计意图**：鼓励选择历史的"广度"，而不是把一种标记刷到爆表。这条同时是《10》挂账 1「殖民原罪 × 背信传统协同公式」的**裁决依据**——见第四节。

### 3. 叙事标记 > 数值修正（门闩原则）

这是全文档**最重要的一条**。

| 类型 | 实现方式 | 举例 |
| :--- | :--- | :--- |
| **叙事标记**（route flag） | **布尔逻辑**，路线锁定/解锁 | "铁屋""殖民原罪""清算能力""解冻传统""影子安全国家" |
| **连续属性** | 百分比数值，仅限少数 | 战争伦理值、殖民遗产值、公众信任指数、后殖民关系质量 |

**玩家记忆点的设计目标**：记忆点必须是"**这条结局路锁了/开了**"，而不是"+25% 还是 +18%"。

**实现**：不要试图给"铁屋"配一个百分比。它的作用是让某些选项在后续时代**变灰不可选**。一旦给门闩配了数值，策划就会忍不住拿它做微调，锁路机制就废了。

**当前需实现为门闩的标记清单**（据《10 感应标记总表》，共 20 个分支产出标记）：神权传统／求知传统／务实传统／包容传统／边界意识／排外传统／技术远见／稳健传统／权谋传统／普世帝国／等级秩序／血统纯正／公开辩论传统／精致控制／羁縻传统／铁血边防／背信传统／城市自治传统／封建稳固／契约博弈传统／神权至上／世俗主权／法治协约传统／血腥记忆／信任契约／精密操控／帝国执念／原则一致性／渐进解体传统／人命优先／效率至上／公共审议传统／文明等级论／人格承认／平等叙事传统／法治战时／集体罪责／影子安全国家／泥潭／代理战争传统／和平斡旋者／铁屋／解冻传统／清算能力。

（此清单由《10》第二节的"写（产出）"列汇总，落地时应由程序从数据表自动生成，此处仅作人工核对基样。）

### 4. 上限封顶

**单时代累计修正绝对值不超过 ±60%。**

超出部分**转化为"极端状态"专属事件**而非继续加成。

- 例：某时代累计已达 +68% → 取 +60%，超出的 +8% 转为触发"极端状态"事件链的判据
- 负向同理（-60% 地板）

**设计意图**：让走极端的代价由**事件叙事呈现**，而非数字雪崩。玩家看到的是"这个社会已经不适合改革了"（事件文本），不是"改革成功率 -73%"。

### 5. 结局结算用档不用值

四维结局评价（统一完成度／人道代价／可持续性／文明丰富度）**按五档制呈现**，内部数值仅作排档依据。

- 玩家看到的是：`人道代价：最低档 —— 名单滚动了九十秒，你跳过了它`
- 玩家**不**看到：一串加总出来的数字

**五档划分（建议初值，待实测调参）**：

| 档位 | 内部区间（示意） | 呈现方式 |
| :--- | :--- | :--- |
| 最低档 | 0–20% | 一句具体的历史细节（"名单滚动了九十秒"） |
| 低档 | 20–40% | 一句具体的历史细节 |
| 中档 | 40–60% | 不给评语，只给档位色块 |
| 高档 | 60–80% | 一句成就描述 |
| 最高档 | 80–100% | 一句成就描述 + 全档案馆解锁 |

**设计意图**：《04》已明确"没有结局能在四个维度上都得高分"。档位制让玩家**感知到维度之间的取舍**（统一完成度最高档时，人道代价必然是最低档），而不是看到一串数字后自行心算。

## 二、四条连续属性的初值定义

《10》已声明这四条是唯一的百分比型连续属性，数值策划需为其定初值区间与计算式：

| 属性 | 区间 | 来源时代 | 落点 | 计算式（待调） |
| :--- | :--- | :--- | :--- | :--- |
| **殖民遗产值** | -100 ~ +100 | 五·大航海 | 殖产 | Σ(本时代殖民/接触事件权重) × 时间衰减，**不衰减**（跨六时代持续） |
| **战争伦理值** | -100 ~ +100 | 八·世界大战 | 核遗 | Σ(底线相关抉择权重) |
| **公众信任指数** | 0 ~ 100 | 九·冷战 | 公信 | f(公众信任事件) × 0.6^代数，起点由"铁屋/解冻/清算"三标记决定 |
| **后殖民关系质量** | -100 ~ +100 | 九·冷战 | 后殖 | 由殖民遗产值 × 去殖民态度修正 |

**关键设计约束**：

- 殖民遗产值**跨六时代持续生效，是全框架唯一跨六时代的单一数值**（《06-第五时代》明确要求）。因此它**豁免第 1 条半衰期衰减**——衰减会让"分水岭"失去意义。
- 公众信任指数的**起点由第九时代三个标记直接决定**（这是《06-第九时代》的明文规定）：
  - 清算社会 → 信任度起点高（"政府证明了自己可被质询"）
  - 铁屋社会 → 信任度起点高（"因为恐惧"）
  - "承诺后的血"社会 → **什么都不信任 → 信任度起点极低**，且 AI 时代接受度基线随之崩塌

**待数值策划确认**：三条非殖民属性的具体初值与权重分配。

## 三、门闩与属性的接口约定

`10_感应标记总表` 已完成全部 50 项（30 主线 + 20 分支）的读写声明。本节规定这些声明在代码里怎么落地。

### 3.1 数据结构约定

```
// 一个叙事标记的最小声明
Marker {
    id:            string      // 全局唯一，如 "iron_house"
    display_name:  string      // 玩家可见名，如 "铁屋"
    type:          enum        // FLAG(门闩) | SCORE(连续值)
    gates:         string[]    // 若 FLAG：它锁/解锁哪些选项 id
    sources:       string[]    // 哪些事件产出它（来自 10 总表）
    decay:         bool        // 是否受半衰期衰减（FLAG 恒为 false）
}
```

### 3.2 互斥声明的落地（《10》挂账 2 已清偿）

《06-第九时代》第 115 行已写明互斥规则，代码必须实现：

- 凡持有 `解冻传统`（含翻车产物 `承诺后的血`）的存档 → 其后**任何**产生 `铁屋` 的事件选项**一律锁定**
- 凡已持 `铁屋` 的存档 → 后续解冻类选项**全部锁定**
- 新增"铁屋"来源事件时，**必须先声明与"承诺后的血"的时序关系**，否则不合入（《00》规则二同源执行）

**实现要点**：这是**存档级全局锁**，不是事件级条件。引擎需要一个 `locked_markers` 集合，在选项可用性判定时统一查询，避免逐事件写 if。

### 3.3 感应触发的实现

《06》各时代脚本的"长期影响"段落大量使用"若你曾……则……"的写法（例：《06-第八时代》"若第一时代获得过'求知传统'标记，此处触发全游戏最美的闭环文本"）。

这类**回声台词**不需要数值，只需要布尔查询：

```
if (save.markers.contains("knowledge_tradition")) {
    showText("岩壁符号研究者协会递交了一份附议……");
}
```

**这是性能最友好、也最容易被策划忘记的一层**。建议在实现前把所有散落在《06》正文里的回声条件**全部抽取为清单**（类似第 3 条的门闩清单），交程序核对遗漏。

## 四、挂账 1 的裁定（殖民原罪 × 背信传统）——2026-10-04 已裁决

《10》第三节第 1 条挂账：第五时代"殖民原罪"累计计数与第三时代"背信传统"标记的协同公式未定，**禁止拍脑袋叠加**。

### ✅ 裁定结论：拆为两个独立维度，取严（max），**不做任何数值叠加**

**2026-10-04 修正说明**：本文档上一版给出的建议解法是 `max + min×0.25`（同维度叠加）。**该建议现已作废，因为它违反了本文档自己的第 3 条铁律。**

作废理由：

- 背信传统在第 60 行门闩清单中，属 **FLAG（布尔门闩）**；殖民原罪对应殖民遗产值，属 **SCORE（-100 ~ +100 连续值）**。
- 铁律 3 明文规定"**禁止给 FLAG 型叙事标记配百分比**"，而 `max + min×0.25` 恰恰要求把 FLAG 折算成数值参与运算。
- 因此**二者不是"同维度"，而是"同作用于信任但不同类型"**。上一版误判为同维度，属推理错误。

### 正确实现

```
维度一：背信传统（FLAG，布尔）
    作用方式：门闩。在第十时代"最后的门槛"处，
    若持有背信传统 → "联邦共治"结局入口关闭（不折算、不衰减）
    来源：《10》一·分支《来自草原的信使》
    关联：全外交信任类选项 -25%（该 -25% 是事件结算时写入 SCORE 的信任基数，
         属一次性结算，不是 FLAG 本身配百分比——这是合规的）

维度二：殖民遗产值（SCORE，-100 ~ +100）
    作用方式：连续值，**豁免半衰期衰减**（第二节约束）
    来源：第五时代殖民/接触事件权重累加
    作用：后殖民关系质量 = 殖民遗产值 × 去殖民态度修正
    关联：文明崩坏阈值联动（《10》二·分支《沉船上的幸存者》）

两者交互：仅在"第十时代结局判定"一处相遇。
    若两者同时为负 → 取更严的那个（max of severity），不叠加。
    实现：severity = max(背信传统 ? 1 : 0, abs(殖民遗产值) / 100)
```

**为什么"取严"而不是"叠加"**：
1. 合规——不给 FLAG 配百分比，铁律 3 得到遵守。
2. 叙事成立——背叛一次殖民一次，**两件事都在加重同一份信誉的损耗**，而不是"两次加起来掉更多血"。玩家的直觉是"我干了三件坏事"，不是"我干了三件坏事所以数值是 1+0.3+0.5"。
3. 实现最简——一个 `max()`，不需要新维度表，不需要额外状态。

**若日后数值策划要改**：唯一允许的改动方向是**拆分得更细**（例如把"背信"限定只作用于盟国关系、"殖民原罪"只作用于殖民地），**绝不允许改为叠加**。叠加方案一律驳回。

## 五、执行顺序（数值岗上手清单）

1. **先读**《05》附录五条铁律 + 本文档第一、二节（不读《06》就动手必崩）
2. **建 Marker 数据结构**（第 3.1 节），把《10》的 50 项声明录成数据
3. **实现三条全局规则**：半衰期衰减、同类不叠加、上限封顶
4. **实现存档级 locked_markers 集合**（第 3.2 节，第九时代互斥声明）
5. **抽取回声台词清单**（第 3.3 节）——最易遗漏，需逐份扫《06》
6. **最后**才做四条连续属性的初值配表（第二节表格）
7. 实现信任维度的"取严"合成（第四节，**已裁决，无需再等确认**）

**禁止事项**（三条红线）：
- 禁止给 FLAG 型叙事标记配百分比
- 禁止把《06》原文数值直接搬进代码不套衰减
- 禁止在玩家可见界面显示百分比数字（《05》原则五）
