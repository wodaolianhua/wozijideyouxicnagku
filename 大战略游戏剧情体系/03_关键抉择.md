# 关键抉择：历史的分叉点

## 设计哲学

每一个重大抉择都不是"好vs坏"的选择题，而是**价值观的碰撞**。选项之间没有绝对的最优解，只有"你愿意承受哪种代价"。后果不会立即完全显现——某些选择的真正代价会在三四个时代之后才浮现，而某些看似错误的选择可能在特定条件下成为通往独特结局的唯一路径。

---

## 一、部落崛起时代

### 抉择1：始祖之路

**背景**：族群面临生存危机，长老会议就未来方向产生严重分歧。你的决定将成为后世传颂的"始祖抉择"，永久塑造文明基因。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 武力征服** | 以战争掠夺资源，强者为尊 | 领土+50%，人口+30%，但外交关系全部恶化；解锁"尚武传统"特质 | 古典时代军事科技研发速度+20%；但文化类科技成本+30%；被征服部落忠诚度永久-20% |
| **B. 农耕定居** | 开垦土地，建立永久聚落 | 粮食产量翻倍，人口自然增长加速；但初期防御力下降，可能遭受游牧袭击 | 经济类科技成本-20%；解锁"土地伦理"叙事线；轴心时代更易发展出自然哲学传统 |
| **C. 贸易网络** | 与周边部落建立交换关系 | 获得稀缺资源，外交关系改善；但自身军事力量薄弱，依赖盟友保护 | 解锁"商人阶层"早期形态；大航海时代提前50年解锁远洋科技；但古典王国时代的集权难度+40% |

### 抉择2：神与人

**背景**：一位极具感召力的祭司宣称获得了神的启示，要求将全部权力归于神庙。支持者众多，但世俗首领们强烈反对。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 神权至上** | 支持祭司，建立神庙统治 | 社会凝聚力大幅提升，内部叛乱风险归零；但决策灵活性下降，改革阻力增大 | 轴心时代宗教类科技成本-30%；但启蒙时代"去神圣化"事件强度+50%；若后续未能成功转型，可能触发"神权僵化"崩溃线 |
| **B. 世俗权威** | 压制祭司，确立首领/王的绝对权力 | 行政效率提升，改革推进顺利；但底层民众不满上升，需要更多镇压成本 | 制度类科技成本-20%；中世纪"教权vs王权"冲突中王权初始优势+30%；但文化认同构建更困难 |
| **C. 二元共治** | 神庙管精神，首领管世俗，相互制衡 | 短期稳定，双方都不满意但都能接受；决策速度变慢，需要频繁协商 | 解锁"协商政治"传统；宪政体制研发前置条件减少一项；但每次重大决策都需要额外的"共识事件"消耗资源 |

### 抉择3：他者之遇

**背景**：侦察队发现了一个语言不通、习俗迥异的邻近族群。他们拥有你们没有的关键资源（优质铜矿/肥沃河谷/特殊作物）。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 驱逐或消灭** | 夺取资源，消除潜在威胁 | 立即获得资源产地；但制造了世代仇敌，边境永无宁日 | 解锁"排外传统"特质；后续所有外交选项信任度-15%；但军事动员效率+10% |
| **B. 通婚融合** | 通过联姻与礼物交换建立亲缘关系 | 缓慢获得资源访问权；人口增加但文化纯度下降 | 解锁"包容传统"特质；轴心时代"文化融合"事件成功率+40%；但早期内部派系斗争概率+20% |
| **C. 隔离共存** | 划定边界，互不侵犯，有限贸易 | 获得稳定资源供应但不控制产地；边境安宁但缺乏深度联系 | 解锁"务实外交"特质；大航海时代处理异文明接触时额外选项"平等条约"可用；但无法触发"深度融合"相关隐藏剧情 |

## 二、古典王国时代

### 抉择1：帝国根基

**背景**：王国已扩张到传统治理模式的极限。地方总督权力过大，中央政令不出都城。必须重构国家架构。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 郡县集权** | 废除世袭领主，派遣流官治理地方 | 中央控制力大幅提升，税收增加；但引发贵族叛乱风险，过渡期动荡 | 官僚选拔制研发速度+30%；但封建契约体系在后续时代不可用；行政效率高但弹性低 |
| **B. 封建分权** | 承认地方领主的世袭权力，换取名义效忠与军事义务 | 立即稳定，扩张成本低；但中央权威被稀释，长期分裂风险上升 | 中世纪秩序过渡更平滑；但工业革命时代的统一市场构建难度+40%；解锁"贵族议会"制度选项 |
| **C. 混合体制** | 核心区直辖，边缘区封建，因地制宜 | 兼顾控制与弹性；但制度复杂度高，腐败风险上升，需要更强的官僚能力 | 解锁"弹性治理"特质；后续所有制度类科技研发时间-10%；但若官僚素质不足则触发"制度溃败"事件 |

### 抉择2：知识垄断

**背景**：文字与书写系统已经成熟，但掌握在极少数人手中。是否推广识字教育？

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 精英垄断** | 知识是统治工具，仅限贵族与官员学习 | 统治阶层素质高，决策质量好；但底层缺乏上升通道，社会僵化 | 轴心时代哲学发展偏向"精英思辨"路线；启蒙时代"普及教育"选项成本+50%；但社会稳定度高 |
| **B. 有限开放** | 商人、工匠子弟可进入专门学校 | 经济活力提升，技术创新加速；但出现不受控的知识阶层 | 经济类科技研发速度+20%；行会自治提前解锁；但"异端思想"事件频率+30% |
| **C. 全民启蒙** | 建立公共教育体系，人人有权识字 | 长期人力资本大幅提升；但短期财政压力巨大，传统精英强烈抵制 | 国民教育体系研发前置条件减少两项；民族主义构建效率+40%；但古典时代末期可能触发"过早觉醒"导致的秩序危机 |

### 抉择3：征服者的道德

**背景**：军队攻陷了一座抵抗顽强的敌对城市。城中有数万平民、珍贵典籍与财富。将士们要求按惯例屠城劫掠。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 屠城立威** | 以恐怖震慑其他抵抗者 | 短期内其他城市望风而降；但制造了深仇大恨，占领区治理成本飙升 | 解锁"恐怖统治"特质；后续征服地区叛乱概率+40%；但军事威慑力+20%；文化类科技研发永久-10% |
| **B. 宽恕怀柔** | 赦免平民，保护典籍，尊重当地习俗 | 占领区迅速稳定，获得当地精英合作；但军队不满，可能哗变 | 解锁"仁政传统"特质；文化同化效率+30%；但下一次战争中军队士气-15%，需要通过其他方式补偿 |
| **C. 强制迁徙** | 将城中精英与工匠迁往都城，摧毁城墙但保留平民 | 获得人才与技术，削弱反抗能力；但难民问题与仇恨并存 | 都城经济+20%，科技研发+10%；但触发"流民危机"事件链；被迁者后代忠诚度需要三代才能恢复 |

## 三、轴心觉醒时代

### 抉择1：思想正统

**背景**：多种哲学/宗教流派激烈竞争，社会思想混乱。你必须选择一种作为国家主导意识形态，或尝试融合。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 独尊一家** | 选定一种思想为正统，压制其他流派 | 思想统一，社会凝聚力回升；但失去思想多样性，创新潜力下降 | 所选思想对应的科技线成本-30%；但其他思想线永久锁定；中世纪"异端运动"强度取决于被压制思想的民间根基 |
| **B. 官方融合** | 由国家主导，将多家思想整合为新的综合体系 | 创造独特的混合意识形态；但各方都不完全满意，执行走样风险高 | 解锁"综合创新"特质；所有文化类科技研发速度+15%；但若融合失败则触发"信仰真空"危机 |
| **C. 自由竞争** | 国家不干预思想市场，让各流派自然演化 | 思想繁荣，创新涌现；但社会共识难以形成，政治极化加剧 | 科学方法论研发前置条件减少一项；但制度类科技成本+25%；启蒙时代"理性共识"更容易达成 |

### 抉择2：帝国遗产

**背景**：旧帝国正在瓦解，边疆失控，蛮族涌入。你是试图挽救帝国，还是接受其死亡并在新基础上重建？

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 全力续命** | 集中一切资源维持帝国统一 | 延缓崩溃，保留更多基础设施；但耗尽国力，转型窗口被错过 | 中世纪起点更高（保留更多古典遗产）；但"改革疲劳"导致后续变革阻力+30%；可能错过轴心时代的思想爆发窗口 |
| **B. 有序退场** | 主动收缩到核心区域，放弃边缘领土 | 核心区域稳定，有余力进行内部改革；但失去大量资源与人口 | 核心区域发展速度+30%；但重新扩张的成本+50%；解锁"凤凰涅槃"叙事线，中世纪后期有独特复兴事件 |
| **C. 拥抱碎片化** | 接受分裂现实，在多个继承国之间建立文化纽带 | 失去政治统一，但保留文明认同；各继承国竞争发展 | 解锁"文化共同体"特质；后续统一战争的合法性+30%；但实际统一难度+40%；大航海时代各继承国可能走向不同道路 |

### 抉择3：蛮族之问

**背景**：大规模民族迁徙浪潮冲击边境。这些"蛮族"既是威胁也是新鲜血液。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 武力排斥** | 筑墙、征兵、驱逐入侵者 | 短期安全，但持续消耗军力；错失融合机会 | 军事支出占比+20%；但保持了文化纯度；中世纪"骑士制度"更易发展；但人口增长受限 |
| **B. 吸纳同化** | 授予土地与公民权，要求接受主流文化 | 人口与兵源增加；但文化稀释，内部摩擦上升 | 人口+30%，军事潜力+20%；但"文化冲突"事件持续三个时代；轴心时代思想体系被迫调整以适应新群体 |
| **C. 雇佣利用** | 将蛮族作为雇佣军使用，不予公民权 | 获得廉价军事力量；但养虎为患，忠诚度极低 | 短期军事实力+40%；但每十年触发一次"雇佣兵叛乱"事件；若处理不当可直接导致政权崩溃 |

## 四、中世纪秩序时代

### 抉择1：信仰与权力

**背景**：教会/宗教机构积累了巨大的财富与影响力，开始挑战世俗统治者的权威。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 教权至上** | 承认宗教机构的最高权威，世俗权力从属于信仰 | 获得宗教合法性加持，民众顺从度高；但丧失政策自主权 | 普世宗教效果+40%；但所有制度改革需要教会批准；启蒙时代"去神圣化"事件强度+60% |
| **B. 王权压制** | 没收教会财产，限制其政治权力 | 财政收入大增，改革空间扩大；但面临绝罚/开除教籍风险，民众可能叛乱 | 制度类科技成本-25%；但文化认同构建难度+30%；宗教改革提前发生且更激进 |
| **C. 政教协约** | 签订正式协议划分权责，相互承认对方领域 | 稳定但模糊的平衡；双方都在试探边界 | 解锁"法治传统"（连最高权力也受契约约束）；宪政体制研发速度+20%；但每次权力交接都可能触发"协约重谈"危机 |

### 抉择2：黑死病应对

**背景**：瘟疫席卷大陆，三分之一人口死亡。社会秩序濒临崩溃。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 铁腕封锁** | 强制隔离，违者处死，军队维持秩序 | 疫情控制较快；但暴政形象固化，幸存者怨恨深重 | 人口恢复速度+20%；但"反抗传统"被植入集体记忆；后续革命事件中民众激进度+30% |
| **B. 放任自流** | 不做强制干预，依靠社区自救与宗教信仰 | 死亡人数更多；但社会自组织能力得到锻炼 | 人口恢复较慢；但"市民自治"传统强化；行会自治效果+30%；文艺复兴提前到来 |
| **C. 科学应对** | 资助医学研究，建立公共卫生体系雏形 | 短期效果有限（医学水平不足）；但积累了宝贵的知识与制度经验 | 科学方法论研发前置条件减少一项；公共卫生体系成为永久资产；但当时被视为"浪费资源"，政治声望-20% |

### 抉择3：城市的命运

**背景**：商业城市日益富裕，要求政治权利。传统土地贵族强烈反对。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 支持城市** | 授予城市自治特许状，扶持市民阶层对抗贵族 | 经济活力爆发，税收结构多元化；但贵族叛乱风险 | 资本主义萌芽提前；工业革命前置条件减少一项；但传统农业区忠诚度下降 |
| **B. 维护贵族** | 压制城市诉求，维持土地贵族的特权地位 | 传统秩序稳定；但经济停滞，人才流失到其他国家 | 社会稳定度高但发展潜力低；可能被邻国超越；解锁"保守现代化"独特路线（效率较低但风险小） |
| **C. 三方博弈** | 在城市与贵族之间玩平衡术，从中渔利 | 中央权力最大化；但两方都不信任你，统治基础脆弱 | 中央集权度+30%；但任何一方的背叛都可能导致崩溃；需要持续投入资源维持平衡 |

## 五、大航海时代

### 抉择1：新大陆的伦理

**背景**：探险队发现了人口稠密的新大陆。当地文明技术水平较低但社会组织复杂。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 殖民征服** | 以武力建立殖民地，掠夺资源，奴役或驱逐原住民 | 巨额财富流入，国力飙升；但道德污点永久化 | 资本积累速度+50%；但"殖民原罪"成为后续时代的持续负面事件；去殖民时代独立运动强度+60% |
| **B. 平等贸易** | 建立公平贸易关系，尊重当地主权 | 利润较低但可持续；获得可靠盟友与文化交流伙伴 | 外交声誉+30%；文化类科技研发+15%；但资本积累速度慢，工业化可能延迟；解锁"后殖民和解"独特结局线 |
| **C. 文化传教** | 以传播信仰/文明为名进行渗透式影响 | 软性控制，成本低；但效果缓慢，可能引发文化反弹 | 文化同化工具+30%；但"文化帝国主义"标签在后续时代被反复提及；若传教失败则双重损失 |

### 抉择2：海洋霸权

**背景**：多个国家争夺海上控制权。你需要决定海军建设的优先级。

| 选项 | 描述 | 即时后果 | 长期影响 |
| :--- | :--- | :--- | :--- |
| **A. 决战舰队** | 建造大型战舰，寻求决定性海战胜利 | 短期制海权；但维护成本极高，技术迭代风险大 | 军事威望+40%；但若战败则海军力量归零；解锁"海权帝国"叙事线 |
| **B. 商船护航** | 以保护贸易航线为核心，海军服务于商业 | 贸易收入稳定增长；但面对敌方主力舰队时处于劣势 | 经济实力持续增长；股份公司效果+30%；但无法阻止敌方对本土的威胁 |

## 抉择联动机制

1. **跨时代因果链**：每个抉择都会生成一个隐藏的"叙事标记"，后续时代的抉择选项会根据标记动态调整。例如：部落时代选择"武力征服"→古典时代"征服者的道德"抉择中"屠城立威"选项的默认倾向+20%→轴心时代"蛮族之问"中"武力排斥"的民意支持度更高。
2. **矛盾累积**：若玩家在不同时代做出了价值观矛盾的抉择（如古典时代"宽恕怀柔"但大航海时代"殖民征服"），会触发"认知失调"事件，迫使玩家在后续做出一致性修正或承受内部撕裂。
3. **隐藏阈值**：某些结局需要特定抉择组合才能触发。例如："文化同化"结局需要在至少6个时代中选择文化/包容类选项；"文明崩坏"结局可以由任意3个时代的极端选项组合触发。
4. **NPC记忆**：重要NPC（顾问、将领、思想家）会记住玩家的抉择历史，并在后续提供基于历史的建议或警告。忽视他们的警告会增加"刚愎自用"隐性计数，影响结局评价。
