# 扩展设计一：起始身份与特殊剧本

> 本文档扩展《01_时代总纲》的起点设计，回答两个问题：玩家以什么身份进入这场五千年（关卡模板），以及"关卡"在大战略游戏里如何成立（特殊剧本库）。

---

## 一、三种起始身份

身份不改变终局的可能性集合（任何身份都可达成十二种结局），改变的是**起跑的叙事与资源结构**。

### 1. 部落首领（默认身份）

- **开局态势**：三百二十七张嘴、一处河谷营地、周边三个未知部落。无边界、无税收、无常备军——你拥有的唯一"制度"是信任。
- **专属机制——"亲力亲为"**：第一时代的所有决策无行政成本，但每次决策消耗"威望"点数；威望靠出席每一场婚礼、判决、救援积累。缺席三次集体劳动，威望开始流失。
- **专属开局事件**：《第一晚》——新首领就职夜，老人问："按老规矩，首领的帐篷应该在最外面挡风口。还是这次，我们换个规矩？"换与不换，第一时代全程的"领袖与族群距离"参数就此定型。
- **长线影响**：部落开局玩家的"文明基因"权重天然偏向协商/包容轴，若最终达成"联邦共治"，结局文本使用"你一生都在练习这件小事：让一屋子人同意"的私人语调。

### 2. 皇帝（困难反向：资源多、自由少）

- **开局态势**：一个已有三百年历史的古典帝国、常备军、官僚系统、以及——一支在首都驻了二十年的禁卫军和三个成年皇子。
- **专属机制——"继承的债"**：开局即带有前任皇帝留下的两项未决危机（一笔打空的国库、一场不义战争遗留的边民怨恨），第一至第二时代的主线部分替换为"收拾遗产"变体。
- **专属开局事件**：《先帝的牌位前》——继位祭典上，太祝宣读先帝遗诏，最后一句是"若汝执政三年，民犹思吾"。游戏真的会在第三年做一次民心对比，无论结果如何，这句话都会在你之后的每次危机中被幕僚提起。
- **长线影响**：帝国开局无法经历"建国叙事"，但解锁独有的"改革者"叙事线——你的统一故事不是从无到有，而是从旧到新；达成"循环重启"结局时，博物馆里最古老的展品是"推翻你祖制的宪法"。

### 3. 城邦执政官（时间压力型）

- **开局态势**：一座八千人的贸易城邦，民选执政官，任期五年，连任需议会批准。你同时面对外部（城邦环伺）与内部（任期）。
- **专属机制——"任期制"**：第一至第二时代每五年触发一次信任投票，政策连续性受"选民耐心"约束——激进改革短期阵痛大会在下一次投票中被清算。这是全框架唯一强制玩家管理"长期正确 vs 短期支持"张力的身份。
- **专属开局事件**：《就职演说》——玩家亲手从三段真实感不同的讲稿中选一段（许诺繁荣／许诺安全／许诺自由），选定的许诺将作为"契约关键词"贯穿全游戏：每次重大危机，市民NPC的对话都会引用你第一天说的那句话。
- **长线影响**：执政官开局的文明天然倾向"宪政体制"路径，但"铁血征服"结局在叙事上更难达成（需要经历"僭主革命"转折事件链——玩家必须在某个时代亲手杀死自己的制度）。

### 身份与自定义文明

地区文明包（东亚／草原／地中海／两河／印度河／安第斯／西非／岛际太平洋等）与身份自由组合；《05_叙事基调建议》的去中心化原则同样适用于起始包——每种身份对每种文明都有独立的开局文本，绝不允许"草原文明+执政官"直接套用"城邦文明+执政官"的文本。

## 二、特殊剧本库（"关卡"的正确形态）

大战略游戏没有"关卡"，有**剧本（Scenario）**：固定开局 + 特制规则修饰 + 专属事件链 + 专属结局变体。以下为本作的剧本池。

### 剧本1：《不会灭亡的帝国》（架空古典线）

- **前提异变**：第一时代的"帝国遗产"抉择中，所有继承者选择了"全力续命"且成功。
- **规则修饰**：玩家从古典时代中期直接入场，背负一个两千年未解体的超级帝国——科技树无"碎片化创新"加成（历史上帝国停滞的部分机制化）；每次时代转换不再崩溃，而是"中兴改革"事件：帝国必须每五百年证明自己还配得上存在。
- **叙事目标**：回答一个反事实——**大一统提前两千年发生，人类是受益还是受损？**
- **专属结局变体**："千年一姓"（世界政府结局的帝国变体：统一极早、极稳、极慢）与"温水"（文明崩坏结局的独有变体：没有崩溃，只有两千年的一致凝固）。

### 剧本2：《归航》（文明流向反转）

- **前提异变**：大航海时代由美洲文明发起——安第斯-中美洲联合船队"发现"了疫病缠身、碎片化的旧大陆。
- **规则修饰**：玩家扮演美利洲文明；科技树重映射（农业与天文满级、冶金半级）；"殖民遗产值"的计算方向反转——这一次，被写在历史耻辱柱上的可能性落在玩家自己身上。
- **叙事目标**：强迫玩家站到历史另一侧，检验自己在"新大陆的伦理"抉择中的真实价值观：当年你谴责的，你会做吗？
- **专属结局变体**：所有十二结局文本使用"反向引用"写法——结局中会朗读真实历史上被殖民者的原话，作为对新殖民者的判决书。

### 剧本3：《黑羊》（瘟疫未至）

- **前提异变**：黑死病被一次极端的隔离政策挡住（即主时间线第一时代选项A的"成功"）。
- **规则修饰**：欧亚人口维持高位，封建解体重于历史；"劳动力稀缺→农奴解放→消费市场"这条隐形因果链断裂——工业革命提前发生但缺少数百年民生积累，劳工苦难剧本加倍残酷；教会因"神迹护佑"权威暴涨，神权路线全局+30%。
- **叙事目标**：揭示框架最反直觉的设计真相——**历史上最大的灾难之一，是人类某些进步的解锁条件。**
- **专属结局变体**："神权复兴"在本剧本中是默认势（历史大潮），玩家若要以无神权方式抵达近未来，需完成"违逆神迹"隐藏抉择链。

### 剧本4：《三船》（微缩文明实验）

- **前提**：无地图优势——玩家是海难幸存者，三艘船、四百人、一座岛。
- **规则修饰**：全十时代浓缩于一个封闭小岛（资源上限、人口上限、外部世界永远未知）；无外交维（或仅有内部派系维），扩张变为人口与制度复杂度；科技只能按"打捞物"解锁——每时代从海里捞上来的旧文明遗物决定科技走向。
- **叙事目标**：剥掉大战略游戏的所有"国家"外壳，只留一个社群的五千年——**如果没有敌人、没有市场、没有对手文明，你还会选择同样的道路吗？**
- **专属结局**：三船结局池独立——"石圈"（重演部落时代）、"分裂之岛"（物种或教派永久分裂的微观版）、"信号"（结局最后：打捞物拼出真相，这座岛曾是上一轮文明的一部分——循环重启结局的隐藏前传）。

### 剧本5：《继承人》（玩家即国家）

- **规则修饰**：玩家不扮演统治者而扮演"国家意志"本身——每时代由系统随机+历史标记加权选出实际执政领袖（可能昏庸、可能英明），玩家以"国家本能"的形式拥有有限的否决与引导点数。领袖作恶，玩家的账本照记。
- **叙事目标**：回答框架埋得最深的问题——**文明的选择究竟是谁做的？如果每一代人都只是接力，"我们"对历史负有什么责任？**
- **专属结局变体**："循环重启"在本剧本中解锁完整版结局动画：十位执政者依次在火塘边坐下又离开，最后只剩椅子与火。

### 剧本结构模板（供扩展用）

```
剧本 = 前提异变点（从主线哪个时代分叉）
     + 规则修饰（科技重映射/属性初值/机制增删）
     + 专属事件链（3-5个独有事件，至少1个反向引用主线）
     + 专属结局变体（复用主结局框架，但文本必须重写）
     + 核心命题（一句话：这个剧本要逼问玩家什么）
```

## 三、剧本与主线的关系

- 主线十时代 = 玩家的"正史"，剧本 = 平行宇宙；剧本通关计入结局博物馆，但带"异史"印章。
- 建议发布节奏：主线 +《三船》首发（互为大小实验），其余剧本作为资料片按"命题递进"排序——《不会灭亡的帝国》（追问稳定）、《归航》（追问立场）、《黑羊》（追问代价）、《继承人》（追问责任）。
