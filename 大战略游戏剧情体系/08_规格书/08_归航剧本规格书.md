# 规格书五：《归航》——文明流向反转完整规格

> 展开《07_01》剧本 2。核心命题：**如果历史站在你这一侧，你会做同样的选择吗？** 本剧本假设大航海时代由美洲文明发起——安第斯-中美洲联合船队"发现"了疫病缠身、碎片化的旧大陆。玩家扮演殖民者，而非被殖民者。

---

## 一、定位与红线

- 单人为主体；一局约 8-12 小时（比主线少 2 个时代，因从大航海时代直接入场）
- **红线**：本剧本不美化殖民行为。所有"殖民成功"的短期收益都伴随不可逆的道德标记积累；所有"拒绝殖民"的选择都面临真实的生存压力。这不是道德说教，而是让玩家**站在自己曾经谴责的位置上**。

### 开局态势

| 要素 | 初始值 | 说明 |
| :--- | :--- | :--- |
| 科技水平 | 农业与天文满级（+3 级），冶金半级（+1 级），军事基础级 | 这是美洲文明的真实历史轨迹——玉米土豆种植技术领先世界，但缺乏铁器与火药 |
| 版图 | 新大陆全境统一（安第斯-中美洲联盟），旧大陆尚未接触 | 起点是"未知的诱惑"而非"已知的威胁" |
| 疾病免疫 | 无。旧大陆的病原体对美洲文明有毁灭性打击（首航死亡率预计 60%+） | 这是本剧本最残酷的设计真相：美洲文明在历史上最大的敌人不是西班牙人，是天花 |
| 航行目标 | "寻找黄金之国"（主观动机）vs "建立贸易网络"（客观最优解） | 玩家的动机将决定后续所有抉择的道德权重 |

### 开局事件：《第一次启航》

三艘远洋船只，四百名船员（含祭司、工匠、战士各三分之一）。出发前夜，祭司警告："海那边可能有我们的神，也可能有我们的死。"这是本剧本唯一一次"不可逆决策"——一旦启航，无法回头。

---

## 二、规则修饰系统

### 1. 殖民遗产值反向计算

主线中殖民遗产值 ≤-50 代表掠夺型帝国，≥0 代表接触型帝国。本剧本**完全反转**：玩家每做出一个"掠夺性"决策，殖民遗产值向 +100 移动；每做出一个"平等接触"决策，向 -100 移动。**最终结算时，这个值不再决定去殖民时代的难度，而决定"被殖民者如何看待你"——而这里的"被殖民者"是旧大陆的欧洲人。** 换句话说：你在本剧本中的"好行为"，会被后世的历史学家称为"负责任的前殖民者"；你的"坏行为"，会被称为"另一个哥伦布"。

### 2. 疫病机制

旧大陆对美洲文明的传染病是本剧本的核心冲突源。每周期触发一次"疫病报告"，玩家必须决定是否采取隔离措施。隔离成本极高（贸易中断、士气下降），但不隔离则可能导致舰队损失 40%-70%。这条线的叙事力量在于：**你面对的不是敌人，是物理法则。**

### 3. 文化反向影响

当美洲文明首次深度接触旧大陆时，会产生独特的"文化冲击"事件链——旧大陆的哲学、宗教、艺术对美洲文明的影响远大于反过来。本剧本独有"知识回流"系统：旧大陆带回的知识越多，美洲文明内部的"传统派 vs 革新派"分裂越深。

---

## 三、专属事件链（5 条）

1. **《新大陆的伦理》（贯穿全剧本）**：每次与旧大陆文明接触时，系统问同一个问题："我们是客人还是主人？"答案序列直接生成"殖民遗产值"的走向。第十时代终局前最后一次确认——这次的答案会出现在结局画面的第一行。
2. **《黄金与天花》**（第二航程）：第一批返航船员带回黄金和天花。祭司要求立即焚毁所有外来物品并召回全部人员；财政官建议继续贸易以获取更先进的武器；军医主张研究天花疫苗。三条路线分别导向"孤立""征服""共存"三种长期路径。
3. **《库斯科的账房》**（启蒙与革命时代）：美洲文明内部爆发"谁该统治"的革命。传统祭司阶层 vs 新兴商人阶层 vs 旧大陆移民后裔。本剧本独有"混合宪政"选项——尝试让三种势力共治，成功率极低但成功后解锁"跨文明治理"特质。
4. **《回声的代价》**（工业巨兽时代）：美洲文明完成了工业化，但代价是彻底抛弃了自身的文化传统。本剧本独有的"文化自杀"事件链——当最后一位会说古克丘亚语的老人去世时，整个文明失去了一种理解世界的方式。
5. **《最后的审判》**（近未来统一时代）：全球统一公投前，旧大陆文明的代表（主要是欧洲后裔）要求你对殖民历史做出正式道歉。接受则获得"道德领导权"但国内民族主义反弹；拒绝则保持"主权尊严"但丧失国际话语权。

## 四、专属结局变体

### 《忏悔录》（文化同化结局的殖民者版本）

- **触发条件**：殖民遗产值 ≥+60（高掠夺倾向）+ 近未来统一时代选择"联邦共治" + 完成"最后的审判"道歉事件。
- **文本差异**：结局不是胜利宣言，而是一份跨越五个世纪的忏悔书。开头引用第一航程祭司的警告："海那边可能有我们的神，也可能有我们的死。"结尾写道："我们找到了神，也带走了死。现在我们要学会如何活着。"

### 《镜像》（铁血征服结局的反转版）

- **触发条件**：殖民遗产值 ≥+80 + 近未来统一时代选择"世界政府" + 全程未采取任何疫病防护措施。
- **文本差异**：统一诏书的措辞与主线铁血征服几乎相同——除了最后一段："我们曾以为自己在征服世界，后来才发现是世界在通过我们征服自己。"结局画面中，博物馆里最古老的展品不是战利品，而是一具天花患者的骸骨。

### 《归还》（隐藏结局）

- **触发条件**：殖民遗产值 ≤-60（高接触倾向）+ 近未来统一时代选择"超越国家" + 完成"回声的代价"文化保存事件。
- **文本差异**：这不是征服的结局，而是归还——把旧大陆归还给旧大陆，把自己归还给自己。结局画面中，三艘远洋船被拆解为木材，用于建造一座跨文明图书馆。旁白只有一句："有些路走远了，是为了知道怎么回家。"

---

## 五、节奏与难度

- 开局疫病风险极高（首航死亡率 60%+），建议新手避免此剧本。老手可通过"疫病免疫"标记降低至 30%。
- 总体难度高于主线（+20% 综合修正），主要源于疫病压力和道德标记的双刃剑效应。
- 失败态唯一：人口 < 40 或舰队在首航中全军覆没（"沉船结局"——本剧本独有的"未完成"失败态）。

## 六、开发规模预估

| 模块 | 内容量 | 复用率 |
| :--- | :--- | :--- |
| 事件文本 | 约主线 25%（5 专属事件链 + 疫病报告模板 10 条） | 与主线共享事件池，仅改写文本层 |
| 地图美术 | 复用主线大航海时代资产 60%，新增"旧大陆初现"特效 | 疫病画面需单独设计 |
| 系统开发 | 疫病模拟引擎 + 殖民遗产值反向计算器 | 复用主线标记管线 |
| 音频 | 复用现有素材，新增"瘟疫钟声"环境音 | 低 |

《归航》作为第三个随箱剧本，回答的是"如果历史站在你这一侧，你会做同样的选择吗"——答案是：大多数人在那个位置上，都会选择黄金而不是天花。
