# 规格书三：《继承人》——"玩家即国家"完整剧本规格

> 展开《07_01》剧本 5。核心翻转：玩家不扮演统治者，扮演**国家意志**本身。每时代由系统选出实际执政领袖，玩家只有有限的否决与引导权。本文档回答一个其余所有文档都回避的问题：**如果每一代人都只是接力，"我"对历史负有什么责任？**

---

## 一、定位与红线

- 单人为主体（接力模式=其社交前身，见《07_04》第四节）；一局约 8-12 小时
- **红线一**：本剧本禁止出现"玩家死亡继承"式伪机制——领袖永远随机+历史加权产生，玩家绝无指定权。
- **红线二**：领袖作恶，玩家的账本照记。系统永不显示"这不是我的选择"式免责提示。这是全部规则里唯一不可谈判的一条——**剧本的存在就是为了拒绝免责。**

## 二、核心循环：每时代一个"执掌回合"

### 1. 领袖产生（时代开始时）

系统按下列权重掷出本时代执政者：

| 权重项 | 说明 |
| :--- | :--- |
| 玩家"制度遗产"（35%） | 上一时代制度类属性决定可产生领袖的**类型池**（君主／执政官／革命委员会……） |
| 历史标记（35%） | "清算先声""法治协约"等标记提高贤能型概率；"铁屋""血腥记忆"提高庸劣型概率——**你的历史决定你下代人的质量，这是全剧本最狠的机制** |
| 纯随机（30%） | 永不归零。世界偶尔发疯，系统必须承认这件事 |

领袖有 4 项隐藏参数：能力／野心／德性／健康。玩家不可见，只能从行为反推（可被其宣传欺骗——能力低的领袖可能演得很像能臣）。

### 2. 国家本能点（玩家唯一权力）

玩家每时代持有 N 点"本能"（N=3+公众信任指数/25，上限 8），可花在四种动作上：

- **引导**（1点）：向领袖推一条政策建议，接受率=能力×德性相关。
- **否决**（2点）：否掉一项已定国策，领袖强行重提需付"威望"代价——昏君可能宁可威望崩塌也要重提。
- **示兆**（1点）：制造一次"天象/舆情/旧事重现"事件（文本引用玩家自己的历史），只影响民心和议会，不影响领袖决策——**你无法命令，只能让某些记忆在场。**
- **附体**（3点，全剧本限一次）：在唯一一次跨时代窗口（时代转换夜），玩家亲自执政一个周期。设计意图：让玩家体验"亲手开车"的诱惑，以及交还方向盘时更深的无力——这唯一一次使用权，多数玩家会花在挽救他们最痛恨的领袖造成的灾难上，而那场灾难本来需要玩家先熬完。

### 3. 账本与史评（时代结束时）

领袖卸任（死亡／罢免／革命——玩家可动用本能促成后两者，但弑君记账加倍）。系统生成《本朝史评》一页：该领袖的成败按**玩家的标记链**归因（"其用人之明，源于汝朝家法百年之训"／"其屠城之手，源于汝第一时代那顶没人收留的帐篷"）。玩家会一次次在自己不愿认领的地方被认领。

## 三、专属事件链（5 条，全给）

1. **《椅子》**：每个执掌回合开场，系统把领袖画像放在火塘边（第一时代的姿势）坐下又离开，只留椅子。第十时代结局动画即此链收束（见《07_01》）。
2. **《好领袖的坏命令》**：能力+德性双高的明君，因"国家账本"的历史标记压力（如"效率至上"遗产）签发一道冷酷命令。玩家是否用否决？否决则明君威望受损、下一回合庸臣得势——**剧本在此逼玩家比较：体面的灾难与不体面的止损。**
3. **《坏领袖的好结果》**：昏君随机掷出的一次鲁莽扩张恰好撞上邻国崩溃，版图大增、民心暴涨。账本照常记他的德性差评，但国家红利照吃。《07_05》因果可视化系统必须在此显示两条分叉线——**成功不等于正确，这条线要画给玩家看。**
4. **《附体之夜》**：见"附体"机制。唯一一次亲自执政的周期里，玩家会直接摸到上一时代自己间接酿成的烂摊子，且只能处理一天。
5. **《最后的问卷》**（第十时代终局前）：系统问玩家一个问题——"以下五千年里，哪三件事是你做的？"玩家只能从全部 30+ 次历史决策中勾选 3 件。勾选结果进入结局文本第一句；系统同时打出"其他人（NPC史官）认为你做了哪三件"。两份名单的重合度即"责任的叙事学"评分——本剧本独有的第五维评价，不计入四维，只呈现，不判定。

## 四、结局适配

十二结局全部可达（剧本只改"谁在开车"，不改路）。但每结局文本增加**双署名**格式：结局诏书末尾署"执掌者名录"（十位领袖）与"国家意志（玩家勾选的三件事）"并列。"循环重启"在本剧本解锁其最纯形态（火塘边依次坐下的椅子，《07_01》已锚定）；"文明崩坏"触发时，《最后的问卷》先于崩坏文本播放——崩坏前最后一眼，玩家被迫自己交出一份责任清单。

## 五、隐藏属性读写声明（按《00》规则二）

- **读**：精神内核（决定领袖类型池）、制度韧性（决定可产生领袖的"上限质量"）、公众信任（本能点基数）、核遗产（附体窗口的时代锁定）。
- **写**：账本归因系统向"殖民遗产值／现代性路径"写入"被动继承修正"（±8%，幅度封顶——**剧本不豁免历史，也不虚构加倍**）。

## 六、产能

文本量约主线 25%（领袖池 12 型×时代适配语料、每时代史评模板、5 事件链）；系统开发 3 模块（领袖掷骰器／本能点／归因引擎），其中归因引擎复用《05》回声台词管线。建议作为第二个随箱剧本（与《三船》构成"最小社群／最小自我"双实验）。
