## 玩家看到的 / 操作的（严格按总纲第 2 节）

1. **地图**：简洁的程序化画法——地形色块 + 路网线 + 部队标记。**不追求写实 3D 建模，不引入外部模型/贴图资产**。文件夹叫"3D地图"只是沿用名，用 2D 俯视或简单 2.5D 表达清楚行军即可。
2. **点选下令**（核心交互，必须顺）：
   - 点己方部队 → 选中（有明确选中态）→ 点地图上的节点 → 单点终点，调 02 的 `MoveTo` 沿路走过去。
   - 连续点多个节点 → 多点折线路径，逐段拐弯（包抄/迂回），调 `MoveVia`，Waypoints = 途经点 + 终点，按点击顺序。
   - 点击位置要**吸附到最近节点**（玩家点的是地图，命令目标只能是路网节点）；吸附成功要有高亮/提示，别让玩家点了没反应。
   - 再次点同一部队可取消选中；未选中部队时点地图只做查看，不下令。
3. **箭头行军**：时间推进时用箭头画出走过的轨迹；**敌军箭头也画**（第一阶段全程可见）。轨迹数据来自 `AdvanceResult.Trails`（每支部队一条 `MarchTrail`，`Points` 首点是本次推进起点，之后每步一个点）。
4. **快进**：一个明显的按钮，调 `FastForward`。无遭遇直接推进到抵达/上限，有遭遇停在事发步。
5. **遭遇展示**：停下后弹出情报面板——我方损失、敌军位置/规模，**损失数字只从 `EncounterEvent.Loss.LossByArmy`（部队Id→损失兵力）读**，不要前端自己算。**不弹 A/B 选项**；玩家关掉面板后自己重新点部队下令应对。
6. **时间显示**：显示当前 `Time`（整数时间步；可自行换算成"第 N 日"之类，但底层用 Time）。推进要有可见反馈。

## 02 算法实际对接事实（已定稿，照此调用）

- 库工程：`E:\军事指挥游戏\02_核心算法\StrategyGame.Core\StrategyGame.Core.csproj`（net8.0），ProjectReference 引用；契约工程由它再引用，你直接 using `StrategyGame.Contracts`。
- 可直接无参构造，默认值即可：
  - `new MarchSimulator()`（内部默认 `PathFinder` + `LossResolver`，接战距离 0.5 世界单位）
  - `new PathFinder()` 只在需要单独预览路径时用。
- 接口签名（契约 `Interfaces.cs`，不许改）：
  - `AdvanceResult Advance(WorldState state, IReadOnlyList<Order> orders, int steps, int seed)`
  - `AdvanceResult FastForward(WorldState state, IReadOnlyList<Order> orders, int maxSteps, int seed)`
- **续走**：`orders` 非空 = 先寻路写入 `PlannedPath/PathIndex` 再推进；`orders` 为空 = 已有计划的部队继续走。所以"下令一次、之后只推进"是正常用法。
- **单步推进量**：兵种速度 ÷（`Edge.Cost` × 边类型倍率 × 进入节点地形倍率）。当前数值：步兵 1.0 / 骑兵 1.8 / 弓兵 1.1 / 器械 0.6；道路 1.0 / 山路 1.6；平原 1.0 / 丘陵 1.25 / 山地 1.6 / 森林 1.15 / 河流 1.4。一条普通道路约 1 步走完。
- 返回的 `State` 是**新对象**，入参 state 不会被改；遭遇损失已同时扣进返回状态的 `Strength`。
- `Encounters` 里每条事件的 `Loss` 已由 02 算好；`Trails` 可直接连成折线。
- 结果码 `Code`：`Ok / NoPath / InvalidTarget / AlreadyArrived`。出现 `NoPath` 等要给出明确提示，别静默失败。
- `seed` 当前不影响结果（损失确定性），固定传 `1` 即可。
- 快进建议 `maxSteps` 给 200；有遭遇时返回的 `State.Time` 就是事发时刻。
