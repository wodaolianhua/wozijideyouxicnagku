操作说明
  1. 点击蓝色我方部队选中，再点一次取消选中。
  2. 点击地图任意位置会自动吸附到最近节点。
  3. 连续点多个节点组成折线（包抄/迂回），右键撤回上一个。
  4. 按 Enter 或点「下令行军」出发，部队沿路线连续行军，直至抵达 / 遭遇 / 你点暂停。
  5. 「推进 1 步」播放单步动画；「快进」是加速播放，逐步走完，遇敌停下弹战报。
  6. 每支部队名条常显状态：待命 / 行军中 / 已抵达 / 遭遇中。
