## 一、改了什么

### 1. 地形浮雕底图（替换原来的深色 Voronoi 色块）

- **高度场**：18 个节点按 `Terrain` 赋基准高度（平原 0.15 / 丘陵 0.42 / 山地 0.82 / 森林 0.30 / 河流 0.05），反距离插值（IDW）铺满画布，再叠加 3 层固定种子值噪声 fBm；N04 / N08 / N13 / N15 附近叠高斯山脊，山地更立体。
- **山体阴影**：西北光源 315° / 45°，由高度梯度算法线；明暗系数 0.5–1.16，陡坡再压暗最多 12%。
  - 叠三层深度线索：邻域高度差做**沟谷软 AO**（谷底压暗、脊线微亮）、沿光照方向做**投影阴影**、受光面偏暖 / 背光面偏冷的**色温分离**。
  - 陡坡混入灰褐**岩石色**，再叠中频起伏纹理，打散大块平滑色斑，避免山顶发白像云雾。
- **高程配色压缩**：低地深绿（≈`#2c4228`）→ 草绿（≈`#405834`）→ 黄绿（≈`#586e42`）→ 土黄（≈`#767048`）→ 褐黄（≈`#8e805c`）→ 浅褐（≈`#9e9274`）→ 米褐（≈`#aaa086`）；高地最亮压到暖卡其（≈`#b6ac94`），不再出现近白色块。不做大面积纯黑，只在画面边缘轻微压暗。
- **等高线**：每 0.08 高度一道，仅画在缓坡，乘 0.85 压暗，保持“极淡”。
- **纹理**：逐像素叠很淡的颗粒噪声。
- **河流**：1 条主河 + 2 条支流，水体 `#319fb4`、深色岸线 `rgba(9,42,48,0.95)`、主河 4.0px / 支流 2.6px；河道做双频横向摆动（振幅约 16px）并让河宽随机变化，支流源头带收窄（taper）。
  - 叠四层：河谷暗带（带阴影模糊）→ 深色岸线 + 水体 → 沿线宽 24%–36% 的浅青水面高光 → 半宽 45% 的青色反光，呈现“水在谷中”的立体感。
- **性能**：整张底图在 `resize` 时烘焙到离屏 canvas（`#terrainGrid`），主循环只贴图，噪声不在每帧跑。

### 2. 弯曲路网与地名

- **路不再横平竖直**：每条边按端点、边类型和固定哈希生成 2–3 个横向偏移控制点，再用 Catmull-Rom 连成曲线，渲染成真正会绕的路径（道路轻微起伏、山路弯得更明显），同一条路双向共用同一条曲线。
- **部队位置也贴合弯道**：`EdgeProgress` 按曲线弧长取样，部队标记沿弯曲路网前进；已走轨迹会把后端给的直线边坐标反投影回对应边，再按弧长取出曲线片段，因此轨迹不会“切角”。
- 计划路径、预览路径同样沿这套弯曲几何绘制。
- 道路暖黄实线 + 深色压边（6.2/3.4/1.2 三层），透明度降低，让地形透出来；山路保持褐色虚线 + 压边。
- **18 个地名常显**：12px 白字 + 3.4px 深色描边；节点为米白圆点 + 深色小影。
- 地名/部队标记布局会读取顶栏、战况面板、操作说明、底部命令区的实际矩形，自动翻到节点上方/侧方，**不压 UI 面板**；说明面板展开时重新布局。

### 3. 部队彩色名条（常显）

- 9 支部队全部常显圆角名条：我方蓝（`#4b9dff` 系）、敌军红（`#ff5f5f` 系）、中立灰；名条内第一行军名（12px 粗体），第二行小字 `${Strength} 兵`（10px），并用细连接线指向部队标记。
- 同节点多支部队自动错开（上下/左右/侧向多候选 + 重叠面积评分），不叠在一起。
- 选中态：名条亮边 + 外发光；悬浮态：白边。
- **名条可点击直接选中部队**（点条等于点标记），命中判定与悬浮提示同步。
- 绘制顺序在箭头之后，保证箭头不会盖住名条。

### 4. 粗曲线行军箭头

- **已走轨迹**：沿弯曲路网取片段后做 Catmull-Rom 平滑，阵营色，宽度由 5.2px 渐变到 7.8px，叠浅色内芯 + 发光；末端 14–18px 大箭头，方向取最后一段切线。
  - 箭头位置从末端回退最多 30px，避免正好被部队标记圆环盖住（截图 `round2_03_行军箭头.png` 中清晰可见）。
- **计划路径**：亮色粗虚线（选中 4.6px/α0.95 + 发光，未选中 3px/α0.3），虚线流动，箭头大小随路径长度自适应。
- **预览路径**：保持细虚线，不画大箭头，避免和正式命令混淆。

### 5. 界面与可读性

- 操作说明面板默认折叠（点了才展开），地图成为主体；顶部/底部 UI 保留原深色玻璃感。
- 所有地图文字都带深色描边，亮地形上依然可读；顶部图例文案改为“浮雕地形 · 等高线”，色块与地形配色同步。

## 五、遗留问题

1. **敌军箭头在当前数据下不出现**：粗箭头逻辑对敌我一视同仁（按阵营色绘制），但 01/02 数据里没有敌军 AI，敌军 `PlannedPath` 始终只有当前节点、不移动，`Trails` 只有 1 个点，画不出轨迹。等后续轮次给敌军下计划或接 AI 后会自动显示，无需再改前端。
2. **部队停在节点时，终点附近的箭头可能被名条压住**：名条绘制优先级更高（按提示词“名条不能被箭头盖住”），此时箭头在行军途中清晰可见；如需终点也常显箭头，可再调整名条避让规则（把轨迹末端纳入避让障碍）。
3. **路网/河流的弯道都是程序化生成**（按边哈希 + 固定噪声），不是真实测绘路径；观感已从“横平竖直”改为会绕的山路，若后续要更接近实景，可把弯道控制点写进 01 数据由算法读取。
4. 地形底图每次 `resize` 重绘一次（非每帧），在 1440×900 下开销可接受；若后续上更大画布可再降采样。
