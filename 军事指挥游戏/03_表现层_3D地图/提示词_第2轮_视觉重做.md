## 一、地形浮雕底图（替换现在的深色 Voronoi 色块）

目标观感：像一张古代军事态势图/地形图，而不是深色战术网格。

1. **高度场**
   - 按 18 个节点的 `Terrain` 赋基准高度：平原 0.15、丘陵 0.42、山地 0.82、森林 0.30、河流 0.05。
   - 用节点做反距离插值（IDW）铺满画布，再叠加 2–4 层 fBm 噪声（固定种子，保证每次一样），山地附近加强脊线。
2. **山体阴影（hillshade）**
   - 光源西北（azimuth 315°、altitude 45°），由高度梯度算明暗，明暗系数约 0.5–1.2。
   - 山地要有明显立体感，平原平缓，森林略带颗粒。
3. **高程配色**
   - 低地：深绿 `#46603a` / `#5d7a45`；中段：黄绿/土黄 `#8a7f4f` / `#a89563`；高地：褐灰/浅米 `#b7a98a` / `#d9d2bf`。
   - 不要大面积纯黑；边缘可轻微压暗，但不要现在的重度暗角。
4. **河流**
   - 从河流节点 N03 / N06 / N11 推导河道，用平滑曲线连接并适当延伸，青色 `#3fb6c9`，深色描边 `#1a5f6b`，宽 3–6px，带轻微发光。
   - 可加 1–2 条支流；河道不要压住地名和军名条。
5. **纹理与等高线**
   - 叠一层很淡的噪声颗粒；可选每 0.08 高度画一条极淡等高线，增强"地形图"感。
6. **性能**
   - 底图只在 `resize` 后重绘一次到离屏 canvas，**不要每帧跑噪声**；主循环只贴图。

## 二、路网与地名

1. 道路：暖黄/土黄实线，深色压边，线宽 2.5–4px，透明度比现在低一点，让地形透出来。
2. 山路：褐色虚线 + 深色压边，线宽 2–3px。
3. 地名：**常显**，白色或浅米色文字，加 1px 深色描边/阴影；节点用小圆点 + 白色细环标记。
4. 字号 12–13px，位置默认在节点下方，遇到边缘自动翻到上方，避免互相压字。

## 三、军队名条（常显）

1. 每支部队显示**常显彩色名条**：圆角矩形底 + 白色粗体军名，参考图的蓝色/红色标签。
2. 颜色沿用现有阵营：我方 `#4b9dff`、敌军 `#ff5f5f`；中立灰。
3. 名条贴在部队标记上方/侧方，带一个小尖角或细线指向标记；同节点多支部队要错开，不能叠在一起。
4. 兵力数字放在名条内第二行小字，或名条右侧的小胶囊；兵种字（步/骑/弓/器）可保留在标记圆内。
5. 选中态：名条加亮边 + 外发光；悬浮态可再加一层白边。
6. 名条不能被箭头盖住；绘制顺序放在箭头之后。

## 四、粗曲线行军箭头（替换细线 + 小箭头）

1. **已走轨迹**（`Trails` 累加）：用平滑曲线（Catmull-Rom 或二次贝塞尔）画**粗箭头**，阵营色，宽 4–8px，末端大箭头（12–18px），可带轻微发光。
2. **计划路径**（`PlannedPath`）：选中部队用亮色粗虚线箭头，未选中降低透明度；箭头大小随路径长度自适应，短路径不要变成一坨。
3. **预览路径**：保持细虚线，不要画大箭头，避免和正式命令混淆。
4. 敌军轨迹同样按阵营色画粗箭头（第一阶段全程可见）。
5. 箭头在线宽上做渐变收窄（起点粗、末端略细或反之），末端箭头方向取最后一段切线。
6. 绘制顺序：地形 → 路网 → 已走轨迹/计划路径 → 节点 → 地名 → 部队标记与名条 → 选中/悬浮效果。
